Theory of Introduction to Image Processing

Mathematical foundations, core concepts, and the science behind digital image manipulation.

1. What is a Digital Image?

A digital image is a discrete representation of a two-dimensional function f(x, y), where x and y are spatial coordinates, and the amplitude of f at any pair of coordinates is called the intensity or gray level of the image at that point.

For a digital image to be processed by a computer, both the spatial coordinates and the intensity values must be digitized — that is, converted into discrete quantities. This process involves two key steps:

Sampling

Discretization of the spatial coordinates (x, y). The continuous image is divided into a grid of small regions called pixels (picture elements). The number of samples determines the spatial resolution.

Quantization

Discretization of the amplitude (intensity) values. The continuous range of brightness is mapped to a finite set of discrete levels. The number of levels determines the radiometric resolution (e.g., 8-bit = 256 levels).

2. Mathematical Representation

A digital image can be represented as a matrix of intensity values. For a grayscale image of size M × N:

f(x, y) = f(0,0)   f(0,1)   ...   f(0,N-1) f(1,0)   f(1,1)   ...   f(1,N-1) ...      ...      ...      ... f(M-1,0)   f(M-1,1)   ...   f(M-1,N-1)

Each element f(x, y) is a pixel value. For an 8-bit image, these values range from 0 (black) to 255 (white). For color images, we have three such matrices — one for each channel (Red, Green, Blue).

Key insight: Image processing is fundamentally about manipulating these matrices using mathematical operations — linear algebra, calculus, statistics, and signal processing techniques.

The field of image processing encompasses a wide range of operations. These are typically organized into a pipeline, from low-level pixel operations to high-level understanding.

Low-Level

  • Image acquisition
  • Preprocessing (denoising, filtering)

  • Restoration (deblurring)

Mid-Level

  • Segmentation (partitioning)

5. Key Theoretical Operations

5.1 Convolution & Filtering

Convolution is the cornerstone of linear image filtering. A small matrix called a kernel (or filter) is slid across the image, and the sum of element-wise products produces the output pixel value.

g(x, y) = ∑i ∑j   f(x+i, y+j) · h(i, j)

Where f is the input image, h is the kernel, and g is the output. Different kernels achieve different effects:

Blurring

Averaging or Gaussian kernels smooth the image by reducing high-frequency noise.

Sharpening

Laplacian or high-pass kernels enhance edges by emphasizing intensity changes.

Edge Detection

Sobel, Prewitt, and Canny operators detect discontinuities in intensity.

5.2 Histogram & Intensity Transformations

The histogram of an image represents the frequency distribution of pixel intensities. It provides valuable information about contrast, brightness, and dynamic range.

h(k) = nk    for   k = 0, 1, 2, ..., L-1

Where nk is the number of pixels with intensity k, and L is the number of possible intensity levels (e.g., 256 for 8-bit).

Histogram equalization is a powerful technique that transforms the image to have a uniform histogram, thereby enhancing contrast:

s = T(r) = (L - 1) ∑j=0r pr(j)

Where pr(j) is the probability of intensity j.

5.3 Edge Detection Theory

Edges correspond to significant local changes in intensity. The gradient of an image ∇f gives the direction and magnitude of the greatest rate of change:

∇f = [ Gx, Gy ]T = [ ∂f/∂x , ∂f/∂y ]T

The gradient magnitude is |∇f| = √(Gx² + Gy²), and the direction is θ = atan2(Gy, Gx). The Canny edge detector is a multi-stage algorithm that includes Gaussian smoothing, gradient computation, non-maximum suppression, and hysteresis thresholding.

Sobel edge detection example
import cv2
import numpy as np

# Load grayscale image
img = cv2.imread('image.jpg', cv2.IMREAD_GRAYSCALE)

# Sobel derivatives
Gx = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
Gy = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)

# Gradient magnitude
magnitude = np.sqrt(Gx**2 + Gy**2)
magnitude = np.uint8(np.clip(magnitude, 0, 255))

5.4 Morphological Operations

Morphology deals with the shape and structure of objects. It uses a structuring element to probe the image. The two fundamental operations are:

Dilation (⊕)

Expands the boundaries of foreground objects. Formally: A ⊕ B = { z | (B̂)z ∩ A ≠ ∅ }. Fills small holes and connects broken segments.

Erosion (⊖)

Shrinks foreground objects. Formally: A ⊖ B = { z | (B)z ⊆ A }. Removes small protrusions and separates touching objects.

Combinations of these give opening (erosion then dilation) and closing (dilation then erosion), which are used for noise removal and shape preservation.

6. Color Theory & Color Spaces

Color is a perceptual phenomenon, but in image processing, we model it mathematically using color spaces. The most common is the RGB space, where each pixel is a combination of red, green, and blue primary colors.

RGB to Grayscale Conversion

Because human vision is more sensitive to green, a weighted sum is used for luminance:

Y = 0.299 R + 0.587 G + 0.114 B

This is known as the luminance formula (ITU-R BT.601). Other color spaces like HSV (Hue, Saturation, Value) and YCbCr separate chromatic information from intensity, which is useful for compression (JPEG) and skin detection.

RGB

Additive color model for displays.

HSV

Cylindrical: Hue (color), Saturation (purity), Value (brightness).

YCbCr

Luma + chroma; used in video and JPEG compression.
