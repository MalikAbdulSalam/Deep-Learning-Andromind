Reading and Displaying an Image

Let's start by loading an image and displaying its basic properties. We'll use OpenCV (cv2) and Matplotlib.

python
import cv2
import matplotlib.pyplot as plt

# Load image (OpenCV loads in BGR format)
image = cv2.imread('sample.jpg')

# Convert BGR to RGB for correct display
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

# Display using Matplotlib
plt.figure(figsize=(8, 6))
plt.imshow(image_rgb)
plt.title('Original Image')
plt.axis('off')
plt.show()

# Print image properties
print(f"Shape: {image.shape}")      # (height, width, channels)
print(f"Data type: {image.dtype}")  # uint8
print(f"Size: {image.size}")        # total pixels

Core Image Processing Operations

Color Space Conversion

Images can be represented in different color spaces — RGB, Grayscale, HSV, etc. Grayscale is often used to simplify processing.

python
# Convert to grayscale
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# Convert to HSV
hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

# Display grayscale
plt.imshow(gray, cmap='gray')
plt.title('Grayscale Image')
plt.axis('off')
plt.show()

Image Filtering & Smoothing

Filters are used to reduce noise or extract features. Gaussian blur is one of the most common smoothing techniques.

python
# Apply Gaussian blur
blurred = cv2.GaussianBlur(image, (15, 15), 0)

# Apply median blur (good for salt-and-pepper noise)
median = cv2.medianBlur(image, 5)

# Edge detection using Canny
edges = cv2.Canny(gray, 100, 200)

plt.figure(figsize=(12, 4))
plt.subplot(131), plt.imshow(cv2.cvtColor(blurred, cv2.COLOR_BGR2RGB)), plt.title('Gaussian Blur')
plt.subplot(132), plt.imshow(cv2.cvtColor(median, cv2.COLOR_BGR2RGB)), plt.title('Median Blur')
plt.subplot(133), plt.imshow(edges, cmap='gray'), plt.title('Canny Edges')
plt.show()

Geometric Transformations

Resize, rotate, and translate images using OpenCV's affine transformations.

python
# Resize to 50% of original
resized = cv2.resize(image, None, fx=0.5, fy=0.5, interpolation=cv2.INTER_LINEAR)

# Rotate 45 degrees around center
(h, w) = image.shape[:2]
center = (w // 2, h // 2)
M = cv2.getRotationMatrix2D(center, 45, 1.0)
rotated = cv2.warpAffine(image, M, (w, h))

# Flip horizontally
flipped = cv2.flip(image, 1)

plt.figure(figsize=(12, 4))
plt.subplot(131), plt.imshow(cv2.cvtColor(resized, cv2.COLOR_BGR2RGB)), plt.title('Resized 50%')
plt.subplot(132), plt.imshow(cv2.cvtColor(rotated, cv2.COLOR_BGR2RGB)), plt.title('Rotated 45°')
plt.subplot(133), plt.imshow(cv2.cvtColor(flipped, cv2.COLOR_BGR2RGB)), plt.title('Flipped')
plt.show()

Histogram & Thresholding

Histograms show pixel intensity distribution; thresholding converts grayscale images to binary.

python
# Histogram of grayscale image
plt.hist(gray.ravel(), 256, [0, 256])
plt.title('Grayscale Histogram')
plt.xlabel('Pixel Intensity')
plt.ylabel('Frequency')
plt.show()

# Binary thresholding
ret, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

# Adaptive thresholding (better for varying illumination)
adaptive = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                 cv2.THRESH_BINARY, 11, 2)

plt.figure(figsize=(10, 4))
plt.subplot(121), plt.imshow(binary, cmap='gray'), plt.title('Binary Threshold')
plt.subplot(122), plt.imshow(adaptive, cmap='gray'), plt.title('Adaptive Threshold')
plt.show()

Image Processing with Pillow (PIL)

Pillow offers a more Pythonic, object-oriented interface for common tasks like cropping, resizing, and enhancing.

python
from PIL import Image, ImageEnhance, ImageFilter

# Open an image
img = Image.open('sample.jpg')

# Display basic info
print(img.format, img.size, img.mode)

# Crop a region (left, upper, right, lower)
cropped = img.crop((100, 100, 400, 400))

# Resize with high-quality resampling
resized = img.resize((300, 200), Image.Resampling.LANCZOS)

# Rotate 90 degrees
rotated = img.rotate(90, expand=True)

# Enhance contrast
enhancer = ImageEnhance.Contrast(img)
enhanced = enhancer.enhance(1.5)  # 1.0 = original

# Apply a blur filter
blurred = img.filter(ImageFilter.GaussianBlur(radius=3))

# Show the results (convert to RGB for display if needed)
cropped.show()
enhanced.show()
Pro tip: Always be mindful of color spaces. OpenCV uses BGR, while Matplotlib and Pillow use RGB. Converting between them prevents color distortion in your visualizations.
