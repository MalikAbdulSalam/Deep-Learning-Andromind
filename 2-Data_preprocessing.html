Computer Vision Image Dataset Pipeline

From Dataset Collection to Model Training

1. Complete Dataset Workflow

Dataset Collection → Data Preprocessing → Data Visualization → Data Annotation → Dataset Splitting → Data Augmentation → Model Training → Evaluation

A high-quality computer vision model depends heavily on the quality and preparation of its dataset. Dataset preparation should be treated as a complete engineering pipeline rather than simply collecting images.

2. Dataset Collection

Dataset collection is the process of gathering images that represent the real-world conditions in which the computer vision model will operate.

2.1 Define the Problem

  • Define the computer vision task.
  • Define the required classes.
  • Determine whether the task is classification, detection, segmentation, or tracking.
  • Define the expected deployment environment.

2.2 Image Sources

  • Industrial cameras
  • CCTV cameras
  • Mobile phones
  • Drones
  • Existing videos
  • Public datasets
  • Client-provided datasets
  • Web-based image sources where licensing permits

2.3 Extract Images from Videos

If the available data is video, frames can be extracted at a suitable frame rate. 

```

Video
↓
Frame Extraction
↓
Image Dataset
↓
Remove Similar / Duplicate Frames
```

2.4 Dataset Diversity

The dataset should represent real-world variations such as:

  • Different lighting conditions
  • Different camera angles
  • Different distances
  • Different object sizes
  • Different backgrounds
  • Different object orientations
  • Partial occlusion
  • Indoor and outdoor conditions
Important: The dataset should represent the conditions the model will encounter after deployment.

3. Data Preprocessing

Data preprocessing prepares raw images and annotations for training. This stage is critical because poor-quality data can significantly reduce model performance.

3.1 Image Cleaning

  • Remove corrupted images.
  • Remove completely irrelevant images.
  • Remove extremely low-quality images.
  • Check image resolution.
  • Check image formats.

3.2 Duplicate Removal

Duplicate or near-duplicate images can cause data leakage and may artificially increase model performance. 

```

Image 001
Image 002  → Duplicate → Remove
Image 003
```

3.3 Image Standardization

  • Convert image formats when necessary.
  • Resize images when appropriate.
  • Normalize pixel values when required by the model.
  • Maintain aspect ratio where appropriate.
For modern YOLO training pipelines, resizing is generally handled by the training pipeline. Avoid unnecessarily modifying the original images before training.

3.4 Annotation Cleaning

  • Check missing labels.
  • Check incorrect class names.
  • Check incorrect bounding boxes.
  • Remove duplicate bounding boxes.
  • Check segmentation masks.
  • Check objects that were accidentally missed.

3.5 Class Balance

Check whether some classes have significantly fewer examples.

Class Number of Objects Status
Bolt 8,000 Good
Nut 7,500 Good
Washer 600 Needs attention

4. Data Visualization

Data visualization allows us to understand the dataset before training the model.

4.1 Image Visualization

  • Display random images.
  • Display images from every class.
  • Check image quality.
  • Check brightness and contrast.
  • Check image dimensions.

4.2 Annotation Visualization

  • Draw bounding boxes on images.
  • Display class names.
  • Display segmentation masks.
  • Check object locations.
  • Identify incorrectly annotated images.
```

Original Image
↓
Draw Bounding Boxes
↓
Display Class Labels
↓
Human Inspection
```

4.3 Dataset Statistics

  • Number of images
  • Number of objects
  • Number of images per class
  • Objects per class
  • Image width and height distribution
  • Object-size distribution
  • Train/validation/test distribution

4.4 Useful Visualization Tools

  • Python
  • Matplotlib
  • OpenCV
  • Pandas
  • Seaborn
  • Roboflow
  • CVAT
  • Label Studio

5. Data Annotation

Annotation means adding the information required by the model to understand the objects or regions in an image.

Common Annotation Types

Task Annotation
Classification Class label
Object Detection Bounding box + class
Segmentation Pixel-level mask
Pose Estimation Keypoints

Common Annotation Formats

  • YOLO
  • COCO
  • Pascal VOC

YOLO Annotation Example

```

class_id x_center y_center width height

0 0.521 0.431 0.215 0.312
```

YOLO bounding-box coordinates are normally normalized between 0 and 1.

6. Dataset Splitting

The dataset should be divided into separate subsets for training, validation, and testing.

Dataset Typical Percentage Purpose
Training 70% Train the model
Validation 20% Tune and monitor the model
Testing 10% Final evaluation
The exact percentages can vary depending on dataset size and project requirements.

Important: Avoid Data Leakage

Similar images, duplicate images, or frames from the same video sequence should not be randomly distributed across train and test sets. Otherwise, the test results may be misleading.

7. Data Augmentation

Data augmentation generates realistic variations of training images to improve model generalization.

  • Horizontal flipping
  • Rotation
  • Scaling
  • Translation
  • Random cropping
  • Brightness adjustment
  • Contrast adjustment
  • Blur
  • Noise
  • Mosaic augmentation
  • MixUp
```

Original Image
↓
Augmentation
↓
┌────┼─────┐
↓    ↓     ↓
Flip Rotate Brightness
↓    ↓     ↓
└────┼─────┘
↓
Additional Training Samples
```
Augmentation should represent realistic conditions. Excessive or unrealistic augmentation can reduce model performance.

11. Key Principle

Garbage In → Garbage Out

A powerful deep learning model cannot compensate for a poor-quality dataset. Good dataset collection, preprocessing, annotation, visualization, and validation are fundamental to achieving reliable computer vision performance.
