1. What is Cross-Validation?

Cross-validation is a model evaluation technique used to estimate how well a machine learning model will perform on unseen data.

Instead of relying on only one training-validation split, we repeatedly train and validate the model using different portions of the dataset.

Complete Dataset
↓
Split into Multiple Parts
↓
Train on Some Parts
↓
Validate on Another Part
↓
Repeat
↓
Calculate Average Performance
Cross-validation is especially useful when the dataset is relatively small and we want a more reliable estimate of model performance.

2. Why Do We Need Cross-Validation?

Suppose we have only 100 samples.

We split them as: 


80 samples → Training
20 samples → Validation

The validation score may depend strongly on which 20 samples happened to be selected.

For example: 


Split 1 → Validation Accuracy = 86%

Split 2 → Validation Accuracy = 91%

Split 3 → Validation Accuracy = 79%

This tells us that the particular split can influence the measured performance.

K-Fold Cross-Validation addresses this by using multiple validation splits.

3. What Does "K" Mean?

In K-Fold Cross-Validation, the dataset is divided into K approximately equal-sized folds.

Common choices are:

  • K = 3
  • K = 5
  • K = 10

For teaching and practical machine learning, K = 5 is a very common choice.

4. Basic K-Fold Example

Suppose we have 100 samples and choose: 


K = 5

The dataset will be divided into approximately: 


100 / 5 = 20 samples per fold
Fold 1 Fold 2 Fold 3 Fold 4 Fold 5

5. How K-Fold Works

The important idea is that each fold becomes the validation set exactly once.

Round 1

Validation Train Train Train Train

Round 2

Train Validation Train Train Train

Round 3

Train Train Validation Train Train

Round 4

Train Train Train Validation Train

Round 5

Train Train Train Train Validation
Every sample gets an opportunity to be part of the validation set, while the remaining samples are used for training.

6. Complete K-Fold Process

  1. Collect the dataset.
  2. Shuffle the dataset when appropriate.
  3. Divide the dataset into K folds.
  4. Select Fold 1 as validation data.
  5. Use the remaining folds for training.
  6. Train the neural network.
  7. Evaluate the model on Fold 1.
  8. Repeat using Fold 2 as validation.
  9. Continue until every fold has been used for validation.
  10. Calculate the average validation performance.

7. Example with K = 5

Round Training Folds Validation Fold
1 2, 3, 4, 5 1
2 1, 3, 4, 5 2
3 1, 2, 4, 5 3
4 1, 2, 3, 5 4
5 1, 2, 3, 4 5

8. Mathematical Formula

Suppose the validation scores from the K folds are: 


S₁, S₂, S₃, ..., Sₖ

The average cross-validation score is: 


Average Score = (S₁ + S₂ + ... + Sₖ) / K

Example 


Fold 1 = 0.88
Fold 2 = 0.91
Fold 3 = 0.86
Fold 4 = 0.90
Fold 5 = 0.89

Therefore: 


Average =
(0.88 + 0.91 + 0.86 + 0.90 + 0.89) / 5

Average = 0.888

Therefore, the average validation accuracy is approximately: 


88.8%

9. Standard Deviation of Performance

We can also calculate the standard deviation of the fold scores.

This tells us how much the performance changes between folds. 


Mean Score = Average of fold scores

Standard Deviation =
Measure of variation among fold scores

For example: 


Fold 1 = 90%
Fold 2 = 91%
Fold 3 = 89%
Fold 4 = 90%
Fold 5 = 90%

Mean = 90%

Standard deviation = small

The model is producing relatively consistent results across different validation folds.

10. K-Fold and Overfitting

K-Fold Cross-Validation can help us obtain a more robust estimate of how a model performs across different subsets of the data.

Dataset
↓
Fold 1 → Train + Validate
↓
Fold 2 → Train + Validate
↓
Fold 3 → Train + Validate
↓
Fold 4 → Train + Validate
↓
Fold 5 → Train + Validate
↓
Average Performance
Cross-validation does not automatically prevent a neural network from overfitting. It provides a better way to evaluate and compare models using different training/validation partitions.

11. Real-World Example

House Price Prediction

Suppose we have a dataset containing 500 houses.

Features include:

  • Area
  • Number of bedrooms
  • Number of bathrooms
  • Location
  • Age of house
  • Parking spaces

Target: 


House Price

We want to build a neural network to predict house prices.

Instead of using only one validation split, we can use: 


K = 5

The model is trained five times.

Fold Validation RMSE
Fold 1 18,500
Fold 2 20,100
Fold 3 17,900
Fold 4 19,200
Fold 5 18,800

We then calculate the average RMSE.

This provides an overall estimate based on all five validation rounds rather than relying on one arbitrary validation split.

12. Important Point for Neural Networks

Traditional machine learning models can often use K-Fold Cross-Validation relatively cheaply.

Neural networks can be much more computationally expensive because the network needs to be trained again for every fold. 


K = 5

Model Training × 5

If each training run takes one hour: 


Approximately 5 training runs

Therefore, K-Fold should be used thoughtfully for large and computationally expensive neural networks.

30. Complete K-Fold Implementation 

import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim

from sklearn.datasets import load_diabetes
from sklearn.model_selection import KFold
from sklearn.preprocessing import StandardScaler


# ============================================
# 1. Load Dataset
# ============================================

data = load_diabetes()

X = data.data.astype(
    np.float32
)

y = data.target.astype(
    np.float32
).reshape(-1, 1)


# ============================================
# 2. Define Model
# ============================================

class RegressionModel(nn.Module):

    def __init__(self, input_size):

        super().__init__()

        self.network = nn.Sequential(

            nn.Linear(input_size, 64),

            nn.ReLU(),

            nn.Linear(64, 32),

            nn.ReLU(),

            nn.Linear(32, 1)
        )


    def forward(self, x):

        return self.network(x)


# ============================================
# 3. K-Fold
# ============================================

kfold = KFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)


# ============================================
# 4. Store Scores
# ============================================

fold_scores = []


# ============================================
# 5. K-Fold Loop
# ============================================

for fold, (train_idx, val_idx) in enumerate(
    kfold.split(X)
):

    print()
    print(
        "=============================="
    )

    print(
        f"Fold {fold + 1}"
    )

    print(
        "=============================="
    )


    # ----------------------------------------
    # Split
    # ----------------------------------------

    X_train = X[train_idx]

    X_val = X[val_idx]

    y_train = y[train_idx]

    y_val = y[val_idx]


    # ----------------------------------------
    # Scale
    # ----------------------------------------

    scaler = StandardScaler()

    X_train = scaler.fit_transform(
        X_train
    )

    X_val = scaler.transform(
        X_val
    )


    # ----------------------------------------
    # Tensor Conversion
    # ----------------------------------------

    X_train = torch.tensor(
        X_train,
        dtype=torch.float32
    )

    X_val = torch.tensor(
        X_val,
        dtype=torch.float32
    )

    y_train = torch.tensor(
        y_train,
        dtype=torch.float32
    )

    y_val = torch.tensor(
        y_val,
        dtype=torch.float32
    )


    # ----------------------------------------
    # New Model
    # ----------------------------------------

    model = RegressionModel(
        input_size=X.shape[1]
    )


    # ----------------------------------------
    # Loss
    # ----------------------------------------

    criterion = nn.MSELoss()


    # ----------------------------------------
    # Optimizer
    # ----------------------------------------

    optimizer = optim.Adam(
        model.parameters(),
        lr=0.001
    )


    # ----------------------------------------
    # Training
    # ----------------------------------------

    epochs = 100

    for epoch in range(epochs):

        model.train()

        predictions = model(
            X_train
        )

        loss = criterion(
            predictions,
            y_train
        )

        optimizer.zero_grad()

        loss.backward()

        optimizer.step()


    # ----------------------------------------
    # Validation
    # ----------------------------------------

    model.eval()

    with torch.no_grad():

        predictions = model(
            X_val
        )

        val_loss = criterion(
            predictions,
            y_val
        )


    # ----------------------------------------
    # Store Score
    # ----------------------------------------

    score = val_loss.item()

    fold_scores.append(
        score
    )


    print(
        f"Validation MSE: {score:.4f}"
    )


# ============================================
# 6. Final Results
# ============================================

print()
print(
    "Fold Scores:"
)

for i, score in enumerate(
    fold_scores
):

    print(
        f"Fold {i + 1}: "
        f"{score:.4f}"
    )


mean_score = np.mean(
    fold_scores
)

std_score = np.std(
    fold_scores
)


print()

print(
    f"Mean MSE: {mean_score:.4f}"
)

print(
    f"Standard Deviation: {std_score:.4f}"
)

32. Calculate RMSE

MSE is useful, but RMSE is easier to interpret because it is in the same units as the target variable. 


RMSE = √MSE

In Python: 

rmse_scores = [
    np.sqrt(score)
    for score in fold_scores
]

mean_rmse = np.mean(
    rmse_scores
)

print(
    "Mean RMSE:",
    mean_rmse
)

33. K-Fold Classification

K-Fold can also be used for classification.

For classification, StratifiedKFold is often more appropriate when class proportions need to be preserved across folds. 

from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)
For classification, especially with imbalanced classes, stratified splitting can help maintain similar class proportions across the folds.

34. Example of Stratified K-Fold

Suppose we have: 


Class 0 = 800 samples

Class 1 = 200 samples

With ordinary K-Fold, class proportions can vary between folds.

Stratified K-Fold attempts to preserve the class distribution in each fold.

35. K-Fold vs Train-Test Split

Feature Train-Test Split K-Fold
Number of Training Runs Usually 1 K times
Validation Sets One K different folds
Computational Cost Lower Higher
Use of Data Some data reserved for validation Every sample is used for validation once
Evaluation Stability Can depend strongly on one split Usually more robust across splits

36. Advantages of K-Fold Cross-Validation

  • Uses different validation subsets.
  • Every sample is used for validation once.
  • Provides an average performance estimate.
  • Can help compare models.
  • Useful for relatively small datasets.
  • Can reveal variation in model performance across data splits.

37. Disadvantages of K-Fold Cross-Validation

  • Training takes longer.
  • Neural networks must be trained multiple times.
  • Computational cost increases with K.
  • It can be impractical for very large deep-learning models.
  • Care must be taken to prevent data leakage.

38. Choosing K

K Typical Use
3 Faster evaluation
5 Common practical choice
10 More validation rounds, higher computational cost
There is no universally optimal value of K. The choice depends on dataset size, computational resources, and the purpose of the evaluation.

39. Data Leakage

Data leakage occurs when information from the validation/test data improperly influences the training process.

Incorrect Scaling 


scaler.fit_transform(X)

Then split into folds

This allows information from all samples to influence the scaler.

Correct Approach 


For each fold:

X_train
   ↓
Fit scaler

X_val
   ↓
Transform using training scaler
Never fit preprocessing transformations using the validation portion of the fold.

41. Important Neural Network Rule

For each fold:
  1. Create a new neural network.
  2. Initialize new weights.
  3. Train only on that fold's training data.
  4. Validate on that fold's validation data.
  5. Store the validation score.

42. K-Fold Does Not Mean Training One Model K Times Continuously

This is an important concept.

49. Quick Revision

K-Fold Cross-Validation divides the dataset into K folds.

Each fold is used as validation data exactly once.

The remaining folds are used for training.

The process is repeated K times.

Finally, the validation scores are averaged. 


Dataset
   ↓
K Folds
   ↓
Train + Validate
   ↓
Repeat K Times
   ↓
Mean Score
   ↓

   ↓
Model Evaluation

50. Final Summary

Cross-validation is a technique for estimating how a model performs on unseen data.

K-Fold Cross-Validation divides the dataset into K folds.

Each fold becomes the validation set once.

The model is trained from scratch for each fold.

The validation scores are then combined, commonly using their mean and standard deviation.

For classification, StratifiedKFold can be useful when maintaining class proportions across folds is important.

K-Fold provides a more extensive evaluation than relying on one arbitrary train-validation split, but it requires additional computation.
