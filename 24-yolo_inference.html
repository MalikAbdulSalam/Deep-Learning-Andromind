YOLOv8 Pretrained Model Inference

Run your trained model.pt using Python and Ultralytics

```
1. Introduction

This guide explains how to run a pretrained or custom-trained YOLOv8 model using Python.

If you already have a trained model such as:

model.pt

you can use it to perform object detection on:

  • Images
  • Videos
  • Webcam
  • Image folders
  • Video streams
  • GPU-powered real-time detection

2. Install Ultralytics

Open Command Prompt, PowerShell, or your Anaconda terminal. 

pip install ultralytics

Verify the installation: 

yolo checks
Note: It is recommended to use a separate Python virtual environment for your YOLO projects.

3. Project Structure

A simple project can look like this: 

yolov8_project/
```

│
├── model.pt
├── test.jpg
├── video.mp4
└── detect.py
```

4. Run YOLOv8 on an Image

Create a Python file named: 

detect.py

Add the following code: 

from ultralytics import YOLO
```

# Load your trained model

model = YOLO("model.pt")

# Run inference

results = model.predict(
source="test.jpg",
conf=0.25,
save=True
)

print("Detection completed!")
```

Output

The detected image will normally be saved inside: 

runs/detect/predict/

5. Run YOLOv8 on Webcam

To use your computer's default webcam: 

from ultralytics import YOLO
```

model = YOLO("model.pt")

model.predict(
source=0,
conf=0.25,
show=True
)
```
source=0 means the default webcam. If you have multiple cameras, you can try source=1, source=2, etc.

Press Q or close the detection window to stop, depending on your environment.

6. Run YOLOv8 on a Video

Put your video in the project folder, for example: 

video.mp4

Then use: 

from ultralytics import YOLO
```

model = YOLO("model.pt")

results = model.predict(
source="video.mp4",
conf=0.25,
save=True,
show=True
)

print("Video detection completed!")
```

The processed video will be saved in the YOLO runs directory.

7. Run Detection on a Folder of Images

You can also process multiple images at once.
```

model = YOLO("model.pt")

model.predict(

```

Example folder: 

images/
```

├── image1.jpg
├── image2.jpg
├── image3.jpg

```
8. Run YOLOv8 Using NVIDIA GPU

If your computer has a compatible NVIDIA GPU, you can use CUDA to accelerate inference. 

from ultralytics import YOLO
```

model = YOLO("model.pt")

model.predict(
source=0,
conf=0.25,
device=0,
show=True
)
```
device=0 tells YOLO to use the first CUDA GPU.

To force CPU inference: 

device="cpu"

9. Complete Recommended Code

The following script gives you a clean starting point for your YOLOv8 projects. 

from ultralytics import YOLO
```

# =========================

# SETTINGS

# =========================

MODEL_PATH = "model.pt"

# Options:

# "test.jpg"       -> image

# "video.mp4"      -> video

# "images/"        -> folder

# 0                -> webcam

SOURCE = "test.jpg"

CONFIDENCE = 0.25

# 0 = NVIDIA GPU

# "cpu" = CPU

DEVICE = 0

# =========================

# LOAD MODEL

# =========================

model = YOLO(MODEL_PATH)

print("Model loaded successfully!")

print("Classes:")
print(model.names)

# =========================

# RUN DETECTION

# =========================

results = model.predict(
source=SOURCE,
conf=CONFIDENCE,
device=DEVICE,
save=True,
show=True
)

# =========================

# FINISHED

# =========================

print("Detection completed!")
```

10. Using a Full Path to model.pt

If your model is stored somewhere else on your computer, use the complete path.

For example: 

MODEL_PATH = r"D:\Freelancing_Projects\bolt_detection\yolov8\best.pt"

The r before the string is useful on Windows because it treats backslashes as normal characters.

11. Check Your Model Classes

You can print the class names stored in your trained model: 

from ultralytics import YOLO
```

model = YOLO("model.pt")

print(model.names)
```

Example output: 

{0: 'bolt', 1: 'nut', 2: 'washer'}

12. Change Confidence Threshold

The confidence threshold controls how confident YOLO must be before displaying a detection.

Lower confidence

conf=0.20

Normal starting point

conf=0.25

Higher confidence

conf=0.50

For example: 

results = model.predict(
source="test.jpg",
conf=0.50,
save=True
```

```
13. Access Detection Results

from ultralytics import YOLO
```

model = YOLO("model.pt")

results = model.predict(
source="test.jpg",
conf=0.25
)

for result in results:

```
boxes = result.boxes

for box in boxes:

    class_id = int(box.cls[0])
    confidence = float(box.conf[0])

    print("Class:", class_id)
    print("Confidence:", confidence)
```

```
15. Basic Workflow

  1. Install Ultralytics.
  2. Put your model.pt in the project folder.
  3. Put your test image/video in the project folder.
  4. Create detect.py.
  5. Load the model using YOLO("model.pt").
  6. Select your source.
  7. Set confidence threshold.
  8. Select CPU or GPU.
  9. Run inference.
  10. Check the generated results.
Important: The same inference code can be used with your custom-trained YOLOv8 model. The model's class names are already stored in the .pt file.
```
