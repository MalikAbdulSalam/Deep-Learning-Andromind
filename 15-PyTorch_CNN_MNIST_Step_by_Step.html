PyTorch CNN on MNIST — Complete Step-by-Step Guide

This guide demonstrates a complete CNN workflow using PyTorch:

Download data → Load data → Inspect images → Create DataLoader → Build CNN → Train → Test → Save model → Load model → Inference on new data

1. What is MNIST?

MNIST is a handwritten digit dataset containing:

  • 60,000 training images
  • 10,000 testing images
  • 10 classes: digits 0 through 9
  • Each image is 28 × 28 pixels
  • Images are grayscale, so they have 1 channel
Image shape = [1, 28, 28]

1 = grayscale channel
28 = height
28 = width

5. Step 4 — Load the Raw MNIST Files

MNIST stores images and labels in a special binary format. We use Python's gzip and struct libraries to read them.

import gzip
import struct
import torch

def load_images(filename):
    with gzip.open(filename, "rb") as f:
        magic, num_images, rows, cols = struct.unpack(
            ">IIII", f.read(16)
        )

        data = f.read()

        images = torch.tensor(
            list(data),
            dtype=torch.float32
        )

        images = images.reshape(
            num_images, 1, rows, cols
        )

        images = images / 255.0

    return images


def load_labels(filename):
    with gzip.open(filename, "rb") as f:
        magic, num_labels = struct.unpack(
            ">II", f.read(8)
        )

        data = f.read()

        labels = torch.tensor(
            list(data),
            dtype=torch.long
        )

    return labels

8. Step 7 — Create DataLoader

DataLoader divides the dataset into small batches. Here we use 64 images per batch.

from torch.utils.data import TensorDataset, DataLoader

train_dataset = TensorDataset(
    x_train, y_train
)

test_dataset = TensorDataset(
    x_test, y_test
)

train_loader = DataLoader(
    train_dataset,
    batch_size=64,
    shuffle=True
)

test_loader = DataLoader(
    test_dataset,
    batch_size=64,
    shuffle=False
)

Instead of giving the CNN all 60,000 images at once, training happens batch by batch.

9. Step 8 — Build the CNN

Our simple CNN contains:

LayerPurpose
Conv2DExtract image features
ReLUAdd non-linearity
MaxPoolingReduce spatial size
FlattenConvert feature maps into a vector
Dense / LinearLearn classification features
Output layerProduce 10 digit scores
class CNN(torch.nn.Module):

    def __init__(self):
        super().__init__()

        self.conv1 = torch.nn.Conv2d(
            in_channels=1,
            out_channels=32,
            kernel_size=3
        )

        self.pool = torch.nn.MaxPool2d(2)

        self.fc1 = torch.nn.Linear(
            32 * 13 * 13,
            64
        )

        self.fc2 = torch.nn.Linear(
            64,
            10
        )

    def forward(self, x):

        x = self.conv1(x)
        x = torch.relu(x)
        x = self.pool(x)

        x = x.view(x.size(0), -1)

        x = torch.relu(self.fc1(x))

        x = self.fc2(x)

        return x

11. Step 10 — Loss Function and Optimizer

model = CNN()

criterion = torch.nn.CrossEntropyLoss()

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)

CrossEntropyLoss measures how different the prediction is from the correct digit.

Adam updates the CNN weights to reduce the loss.

12. Step 11 — Train the CNN

epochs = 5

for epoch in range(epochs):

    model.train()

    total_loss = 0

    for images, labels in train_loader:

        outputs = model(images)

        loss = criterion(
            outputs,
            labels
        )

        optimizer.zero_grad()

        loss.backward()

        optimizer.step()

        total_loss += loss.item()

    average_loss = (
        total_loss / len(train_loader)
    )

    print(
        f"Epoch {epoch + 1}/{epochs} "
        f"Loss: {average_loss:.4f}"
    )

What happens during training?

Image
  ↓
CNN prediction
  ↓
Calculate Loss
  ↓
Backpropagation
  ↓
Update weights
  ↓
Next batch
  ↓
Repeat

13. Step 12 — Test the Model

Testing uses images that were not used to train the CNN.

model.eval()

correct = 0
total = 0

with torch.no_grad():

    for images, labels in test_loader:

        outputs = model(images)

        _, predicted = torch.max(
            outputs, 1
        )

        total += labels.size(0)

        correct += (
            predicted == labels
        ).sum().item()

accuracy = 100 * correct / total

print(f"Test Accuracy: {accuracy:.2f}%")
Important: Test accuracy measures how well the trained model generalizes to the separate MNIST test set.

15. Step 14 — Load the Trained Model

For inference, we do not train again. We create the same CNN architecture and load the saved weights.

model = CNN()

model.load_state_dict(
    torch.load(
        "mnist_cnn.pth",
        weights_only=True
    )
)

model.eval()

print("Model loaded!")

Now we want to give the CNN an image it has never seen before.

Put your new digit image here:

new_data/

The image should contain one handwritten digit. For the simplest example, use a roughly square image with a black background and a white digit, similar to MNIST.

Load the new image

from PIL import Image

image = Image.open(
    "new_data/digit.png"

image = image.resize((28, 28))

Convert it to a PyTorch tensor

import torchvision.transforms as transforms

transform = transforms.ToTensor()

image_tensor = transform(image)

Normalize the image

MNIST training images were normalized by dividing pixel values by 255. ToTensor() already converts the PIL image to the range 0–1.

Add the batch dimension

image_tensor = image_tensor.unsqueeze(0)

19. Complete Inference Code

Once the model has been trained and mnist_cnn.pth exists, the inference script can be very small:

import torch
from PIL import Image
import torchvision.transforms as transforms

# Same CNN definition must exist
# class CNN(nn.Module):
#     ...

# Load model
model = CNN()

model.load_state_dict(
    torch.load(
        "mnist_cnn.pth",
        weights_only=True
    )
)

model.eval()

# Load new image
image = Image.open(
    "new_data/digit.png"
).convert("L")

# Resize
image = image.resize((28, 28))

# Convert to tensor
transform = transforms.ToTensor()

image_tensor = transform(image)

# Add batch dimension
image_tensor = image_tensor.unsqueeze(0)

# Prediction
with torch.no_grad():

    output = model(
        image_tensor
    )

    prediction = torch.argmax(
        output,
        dim=1
    ).item()

print("Predicted digit:", prediction)

Common issue with new images: MNIST has a particular visual format. A phone/photo image or a digit with the opposite foreground/background may not work well without preprocessing. For the first inference exercise, use a simple 28×28-style handwritten digit image that resembles MNIST.
