LabelImg Setup from GitHub

This guide explains how to install and configure the GitHub version of LabelImg on Windows using a dedicated Conda environment.

1. Create a Conda Environment

```

It is recommended to use Python 3.10 for this LabelImg setup.

conda create -n anno python=3.10 -y
```

conda activate anno
```

Verify Python:

python --version

Expected:

Python 3.10.x
```

2. Download LabelImg from GitHub

```

Go to the directory where you want to keep the project:

cd "D:\Freelancing Projects"

Clone the repository:

git clone https://github.com/HumanSignal/labelImg.git

Enter the LabelImg directory:

cd labelImg

Your directory should now be:

D:\Freelancing Projects\labelImg
```

3. Install Required Packages

```

Install PyQt5 and lxml:

pip install PyQt5 lxml

Check PyQt5:

pip show PyQt5
```

4. Generate the Qt Resources File

```

The GitHub source contains resources.qrc, but the generated Python file libs/resources.py may not exist after cloning.

Install the Qt resource compiler:

pip install pyqt5-tools

Then, from the LabelImg root directory, run:

pyrcc5 -o libs\resources.py resources.qrc

This generates: 

libs\resources.py
Important: Do not manually create an empty resources.py. It should be generated from resources.qrc.

If Windows cannot find pyrcc5, check:

dir "%CONDA_PREFIX%\Scripts\pyrcc5.exe"

If it exists, run:

"%CONDA_PREFIX%\Scripts\pyrcc5.exe" -o libs\resources.py resources.qrc
```

6. Configure Your Own Classes

```

LabelImg can use a predefined class list. Look for: 

data\predefined_classes.txt

For example, replace its contents with:

bolt
```

nut
washer
damaged_bolt
```

Save the file and restart LabelImg.

Result: When creating a bounding box, your own class names can be selected instead of the default classes.
```

7. Start LabelImg

```

From:

D:\Freelancing Projects\labelImg

run:

python labelImg.py

The LabelImg GUI should open.

```

8. Open Your Image Folder

```

Inside LabelImg:

  1. Click Open Dir.
  2. Select your image directory.
  3. LabelImg will display the images one by one.

For example:

D:\Freelancing Projects\bolt_detection\pitch_-60
```

9. Select YOLO Annotation Format

```

If you are going to train YOLOv8, YOLO11, or another YOLO model, select the YOLO format in LabelImg.

Make sure you select YOLO format before starting your annotations.
```

10. Create Bounding Boxes

```

You can press:

W

or click Create RectBox.

Then:

  1. Click and drag around the object.
  2. Select your class name.
  3. Press OK.
  4. Save using Ctrl + S.
```

15. Important YOLO Class Number Rule

```

YOLO does not store the class name directly in every annotation. It stores the class ID.

For example:

0 = bolt
```

1 = nut
2 = washer
```

A YOLO annotation may look like:

0 0.512 0.423 0.120 0.180

The first number 0 means the object belongs to class bolt.

```

16. If You Get the PyQt5 drawLine Error

```

Some LabelImg versions can produce an error similar to: 

TypeError: arguments did not match any overloaded call:
```

drawLine(...)
```

This occurs when floating-point coordinates are passed to Qt's drawLine().

Open:

libs\canvas.py

Find the crosshair drawing section and make sure it uses integer coordinates:

p.drawLine(
int(self.prev_point.x()),
0,
int(self.prev_point.x()),
int(self.pixmap.height())
```

)

p.drawLine(
0,
int(self.prev_point.y()),
int(self.pixmap.width()),
int(self.prev_point.y())
)
```

Save the file and restart LabelImg.
```
