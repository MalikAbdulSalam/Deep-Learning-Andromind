Activation Functions for Neural Networks

Definition: An activation function is a mathematical function applied to the output of a neuron. It determines whether and how strongly the neuron should activate and introduces non-linearity into a neural network.

Without activation functions, a neural network made entirely of linear operations would still behave like a single linear transformation, even if it contained many layers.

Input ↓ Weighted Sum ↓ z = Σ(wx) + b ↓ Activation Function ↓ Neuron Output

1. Why Do We Need Activation Functions?

The main purpose of an activation function is to introduce non-linearity into the neural network.

Real-world problems such as image recognition, speech recognition, object detection, and natural language processing are generally not simple linear problems.

Important: If every layer of a neural network uses only a linear function, stacking many layers does not give the network the expressive benefit of nonlinear transformations.

2. Activation Function in a Neuron

A neuron first calculates a weighted sum:

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

The activation function is then applied:

y = f(z)
Inputs ↓ Weights ↓ Weighted Sum + Bias ↓ z ↓ Activation Function ↓ Output

3. Threshold Activation Function

What is Threshold Activation?

The threshold function, also called the step function, produces a binary output.

If the input is greater than or equal to a threshold, the output is 1. Otherwise, the output is 0.

f(x) = 1   if x ≥ 0

0   if x < 0

Output Range

0 or 1

Example

z = 2.5

Since 2.5 ≥ 0:

Output = 1

Applications

  • Traditional perceptron
  • Simple binary decision systems
  • Historical neural-network models

Advantages

  • Very simple
  • Easy to understand
  • Produces a clear binary decision

Disadvantages

  • Not differentiable at the threshold
  • Gradient is zero almost everywhere
  • Not suitable for modern gradient-based deep learning

4. Sigmoid Activation Function

What is Sigmoid?

Sigmoid is an S-shaped activation function that converts any real-valued input into a value between 0 and 1.

σ(x) = 1 / (1 + e-x)

Output Range

0 < σ(x) < 1

Example

σ(0) = 0.5
σ(2) ≈ 0.881
σ(-2) ≈ 0.119

Interpretation

Because the output is between 0 and 1, sigmoid is useful when an output needs to represent a probability-like value for a binary classification task.

Advantages

  • Output is bounded between 0 and 1
  • Smooth and differentiable
  • Useful for binary classification output layers

Disadvantages

  • Can suffer from vanishing gradients
  • Not zero-centered
  • Can become saturated for very large positive or negative inputs

Common Use

Binary Classification Output Layer
Example: Cat vs Not Cat

5. ReLU Activation Function

What is ReLU?

ReLU stands for Rectified Linear Unit. It is one of the most commonly used activation functions in modern deep neural networks.

ReLU(x) = max(0, x)

Therefore:

ReLU(x) = x   if x > 0

ReLU(x) = 0   if x ≤ 0

Examples

ReLU(5) = 5
ReLU(0) = 0
ReLU(-3) = 0

Output Range

[0, ∞)

Advantages

  • Computationally simple
  • Efficient to calculate
  • Usually provides stronger gradients than sigmoid/tanh in positive regions
  • Widely used in hidden layers of deep networks

Disadvantage

ReLU can suffer from the dying ReLU problem.

If a neuron stays in the negative region, its gradient can remain zero and the neuron may stop updating effectively.

Common Applications

  • Convolutional Neural Networks (CNNs)
  • Image Classification
  • Object Detection
  • Computer Vision
  • Deep Neural Networks

6. Tanh Activation Function

What is Tanh?

Tanh, or hyperbolic tangent, is an S-shaped activation function that maps values between -1 and +1.

tanh(x) = (ex - e-x) / (ex + e-x)

Output Range

-1 < tanh(x) < 1

Examples

tanh(0) = 0
tanh(2) ≈ 0.964
tanh(-2) ≈ -0.964

Advantages

  • Zero-centered output
  • Useful when negative and positive values are meaningful
  • Smooth and differentiable

Disadvantages

  • Can suffer from vanishing gradients
  • Saturates for large positive and negative values

Common Applications

  • Some recurrent neural networks
  • Historical neural-network architectures
  • Situations where zero-centered activations are useful

7. Softmax Activation Function

What is Softmax?

Softmax converts a vector of raw scores, often called logits, into a probability distribution across multiple classes.

Softmax(zᵢ) = ezᵢ / Σ ezⱼ

The probabilities produced by softmax sum to 1.

P₁ + P₂ + ... + Pₙ = 1

Example

Suppose a neural network produces these logits:

[2.0, 1.0, 0.1]

Softmax converts them approximately into:

[0.659, 0.242, 0.099]

The probabilities add up to approximately:

0.659 + 0.242 + 0.099 ≈ 1

Output Range

Each output is between 0 and 1.

Common Application

Multi-Class Classification

Example:

  • Cat
  • Dog
  • Horse

Softmax can produce a probability for each class.

Important

Softmax is normally applied to a vector of class scores rather than independently to a single scalar.

8. Comparison of Activation Functions

Function Output Range Nonlinear? Common Use Main Issue
Threshold 0 or 1 No useful smooth gradient Perceptron Not suitable for gradient-based deep learning
Sigmoid 0 to 1 Yes Binary classification output Vanishing gradients
ReLU 0 to ∞ Yes Hidden layers, CNNs Dying ReLU
Tanh -1 to 1 Yes Some RNNs / hidden layers Vanishing gradients
Softmax 0 to 1 per class Yes Multi-class classification output Can become numerically sensitive with extreme logits if implemented naively

9. When Should We Use Each Activation Function?

Situation Common Choice
Traditional perceptron Threshold / Step
Hidden layers of many deep networks ReLU or related variants
Binary classification output Sigmoid
Multi-class classification output Softmax
Some recurrent architectures Tanh

10. Easy Way to Remember

Threshold ↓ Binary Decision 0 or 1 Sigmoid ↓ Binary Probability 0 to 1 ReLU ↓ Deep Network Hidden Layers 0 to ∞ Tanh ↓ Zero-Centered -1 to +1 Softmax ↓ Multi-Class Probabilities Sum = 1

11. Activation Functions in a Neural Network

┌── ReLU ──► Input ──► Hidden Layer ──► Hidden Layer ──► Output │ │ └── ReLU ──────┘ Binary Classification: Output → Sigmoid Multi-Class Classification: Output → Softmax

A common architecture might therefore use ReLU in hidden layers and use an output activation appropriate to the prediction task.

12. Key Points

  • Threshold: Produces a hard binary decision and is associated with the traditional perceptron.
  • Sigmoid: Maps a scalar to the range 0 to 1 and is commonly used for binary classification outputs.
  • ReLU: Outputs zero for negative inputs and the input itself for positive inputs; widely used in hidden layers.
  • Tanh: Maps values to approximately -1 to +1 and is zero-centered.
  • Softmax: Converts multiple logits into a probability distribution whose values sum to 1, commonly for multi-class outputs.

13. Overall Concept

Remember: The activation function is not simply an extra calculation. It is what allows neural networks to model complex nonlinear relationships.
