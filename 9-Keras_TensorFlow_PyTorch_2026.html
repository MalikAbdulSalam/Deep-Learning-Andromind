Keras is designed to make deep-learning development easier.

For example:

import keras
from keras import layers

model = keras.Sequential([
    layers.Dense(64, activation="relu"),
    layers.Dense(32, activation="relu"),
    layers.Dense(1, activation="sigmoid")
])

You don't have to write the low-level training machinery yourself.

Keras 3 can use:

Keras
 ├── TensorFlow backend
 ├── PyTorch backend
 └── JAX backend

This is one of the biggest changes compared with older Keras.

Advantages

  • Easy to learn
  • Very clean API
  • Excellent for teaching
  • Fast prototyping
  • model.fit() makes standard training simple
  • Can use TensorFlow, PyTorch or JAX as backend
  • Can work with PyTorch DataLoader and TensorFlow tf.data
  • Good model portability

Keras officially describes itself as a multi-framework deep-learning API.

Disadvantages

If you are doing highly customized research or need very low-level control, native PyTorch can be more natural.

3. TensorFlow

TensorFlow is a complete machine-learning ecosystem.

Typical architecture:

TensorFlow
│
├── Tensor operations
├── Automatic differentiation
├── Neural networks
├── GPU/accelerator support
├── tf.data
├── Distributed training
├── Model serving
└── Deployment ecosystem

Example:

import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation="relu"),
    tf.keras.layers.Dense(32, activation="relu"),
    tf.keras.layers.Dense(1, activation="sigmoid")
])

model.compile(
    optimizer="adam",
    loss="binary_crossentropy",
    metrics=["accuracy"]
)

model.fit(X_train, y_train, epochs=10)

One important current change: TensorFlow 2.16+ uses Keras 3 by default, while legacy Keras 2 can still be used separately through tf_keras.

So today you should not think:

TensorFlow = old Keras

Instead:

TensorFlow = framework

Keras 3 = high-level API
             ↓
       TensorFlow backend

4. PyTorch

PyTorch is a complete deep-learning framework.

Example:

import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 64),
    nn.ReLU(),
    nn.Linear(64, 32),
    nn.ReLU(),
    nn.Linear(32, 1)
)

Training:

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)

for epoch in range(10):

    optimizer.zero_grad()

    output = model(X_train)

    loss = criterion(output, y_train)

    loss.backward()

    optimizer.step()

PyTorch provides tensors, automatic differentiation, neural-network modules, optimization, GPU/accelerator support, distributed training, and compilation facilities.

And importantly for 2026, PyTorch 2.14 was released in September 2026, continuing development around compilation, distributed training, accelerator support, and performance.

5. Keras vs PyTorch for Learning

This is an important distinction.

Keras

model.fit(
    X_train,
    y_train,
    epochs=20,
    batch_size=32
)

A lot of training machinery is abstracted.

PyTorch

for epoch in range(20):

    optimizer.zero_grad()

    prediction = model(X_train)

    loss = criterion(prediction, y_train)

    loss.backward()

    optimizer.step()

You see more of what is actually happening.

Therefore, for learning how deep learning works internally, PyTorch is particularly useful.

8. What About Keras 3 in 2026?

I would still teach Keras.

But I would teach it differently than older courses.

Don't teach:

Keras = TensorFlow

Teach:

Keras 3
   │
   ├── TensorFlow
   ├── PyTorch
   └── JAX

Keras 3 explicitly supports these backends and is designed to allow the same high-level model code to work across them when using compatible Keras APIs.

This makes Keras valuable for students because they learn a clean high-level API without being locked into one backend.

9. What About TensorFlow?

TensorFlow is still important.

I would not remove TensorFlow from an AI/DL curriculum.

It remains useful for:

  • production ML systems
  • TensorFlow ecosystem
  • tf.data
  • TensorFlow Serving
  • TensorFlow\.js
  • TensorFlow Lite
  • existing enterprise code
  • Google ecosystem
  • TPU-oriented workflows

Keras 3 can also export/use models with TensorFlow deployment tooling, which is one of its ecosystem advantages.
