Bias and Gradient Descent in Deep Learning

1. What is Bias in a Neural Network?

Definition: Bias is a learnable parameter in a neural network that allows a neuron to shift its activation function. It gives the neuron additional flexibility to fit the training data.

A neuron generally calculates:

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

Then:

y = f(z)

Where:

  • x = input
  • w = weight
  • b = bias
  • f = activation function
  • y = output

2. Why Do We Need Bias?

Consider a simple linear equation:

y = wx + b

Here, w controls the slope and b controls the vertical shift.

Without Bias: y = wx / / / / ---/---------------- x With Bias: y = wx + b / / / -----/-------------- x ↑ Shift

In a neural network, bias gives each neuron the ability to shift its activation rather than forcing the activation to pass through a fixed point.

3. Example of Bias

Suppose:

x = 5
w = 2
b = 3

Then:

z = wx + b
z = (2 × 5) + 3
z = 13

Without bias:

z = (2 × 5) = 10
Bias allows the neuron to adjust its output independently of the weighted input contribution.

4. Is Bias Learned?

Yes. Bias is a learnable parameter, just like weights.

Initial: Weight = 0.5 Bias = 0.2 ↓ Training ↓ Updated: Weight = 0.63 Bias = 0.17

During training, backpropagation calculates the gradient of the loss with respect to the bias, and the optimizer updates it.

b(new) = b(old) − η × ∂L/∂b

5. What is a Gradient?

A gradient tells us how the loss changes when a model parameter changes.

For a weight:

∂L / ∂w

This tells us how much the loss changes with respect to the weight.

Similarly:

∂L / ∂b

tells us how the loss changes with respect to the bias.

6. What is Gradient Descent?

Gradient Descent is an optimization algorithm used to minimize a loss function by repeatedly updating the model's parameters in the direction that reduces the loss.

The basic idea is:

High Loss ● \ \ \ ● \ ● \ ● ← Minimum Loss

The goal is to find parameter values that produce a small loss.

7. Gradient Descent Formula

For a weight:

w(new) = w(old) − η × ∂L/∂w

For a bias:

b(new) = b(old) − η × ∂L/∂b

Where:

Symbol Meaning
w Weight
b Bias
η Learning rate
L Loss function
∂L/∂w Gradient of loss with respect to weight
∂L/∂b Gradient of loss with respect to bias

8. Why Do We Subtract the Gradient?

The gradient points in the direction of increasing loss. Therefore, we move in the opposite direction to reduce the loss.

Gradient Direction ↑ │ │ ● │ ↓ Opposite Direction = Lower Loss
Remember: Gradient tells us the direction of increasing loss. Gradient descent moves in the opposite direction.

9. What is Learning Rate?

The learning rate controls how large each parameter update is.
New Parameter = Old Parameter − Learning Rate × Gradient

Small Learning Rate

Small Steps: ● \ ● \ ● \ ● \ ●

Training may be slow but updates can be more controlled.

Large Learning Rate

Large Steps: ●──────►● │ ▼ ●──────►● │ ▼

Training can overshoot a minimum and may become unstable.

10. Types of Gradient Descent

The three fundamental forms of gradient descent are:

11. Batch Gradient Descent

Batch Gradient Descent calculates the gradient using the entire training dataset before updating the model parameters.

Example

Suppose we have 10,000 training samples.

10,000 Samples ↓ Calculate predictions for all ↓ Calculate total/average loss ↓ Calculate gradients ↓ Update weights ↓ Next iteration

Advantages

  • Stable gradient estimates
  • Deterministic updates for a fixed dataset/order
  • Can work well when the dataset fits comfortably in memory

Disadvantages

  • Can be computationally expensive for large datasets
  • Requires processing the full dataset for each update
  • Parameter updates happen less frequently

12. Stochastic Gradient Descent (SGD)

Stochastic Gradient Descent updates the model using one training sample at a time.
Sample 1 ↓ Prediction ↓ Loss ↓ Gradient ↓ Update Sample 2 ↓ Prediction ↓ Loss ↓ Gradient ↓ Update Sample 3 ↓ ...

Advantages

  • Frequent parameter updates
  • Low memory requirement
  • Can make progress quickly on large datasets
  • The noise in updates can sometimes help escape shallow regions

Disadvantages

  • Updates are noisy
  • Loss may fluctuate significantly
  • May require careful learning-rate scheduling

13. Mini-Batch Gradient Descent

Mini-Batch Gradient Descent divides the training dataset into small batches and updates the parameters after each batch.

For example:

Dataset = 10,000 samples Batch 1 → 32 samples → Update Batch 2 → 32 samples → Update Batch 3 → 32 samples → Update ... Batch N → 32 samples → Update

Common batch sizes include:

  • 16
  • 32
  • 64
  • 128
  • 256

The appropriate batch size depends on the model, dataset, hardware, and training setup.

Advantages

  • More efficient than processing one sample at a time on modern hardware
  • Usually more stable than pure SGD
  • Works well with GPU parallelism
  • Balances computational efficiency and update frequency

Disadvantages

  • Requires choosing a batch size
  • Still contains some gradient noise
  • Large batches require more memory

15. Epoch, Batch and Iteration

These terms are important when working with mini-batch training.

Epoch: One complete pass through the entire training dataset.
Batch: A subset of training samples processed together.
Iteration / Step: One parameter update, normally after processing one batch.

Example

Suppose:

  • Dataset = 1,000 samples
  • Batch size = 100
Iterations per Epoch = 1000 / 100 = 10

Therefore:

1 Epoch │ ├── Batch 1 → Update ├── Batch 2 → Update ├── Batch 3 → Update ├── ... └── Batch 10 → Update

16. Gradient Descent vs Optimizers

Gradient Descent is the basic optimization idea. Modern deep learning often uses improved optimizers that modify how gradients are accumulated or how parameter updates are scaled.

Important optimizers include:

Optimizer Main Idea
SGD Gradient-based updates, optionally with momentum
Momentum Uses a moving direction from previous gradients
AdaGrad Adapts learning rates based on accumulated squared gradients
RMSprop Uses an exponentially weighted average of squared gradients
Adam Combines momentum-like first-moment tracking with second-moment scaling
AdamW Adam-style adaptive optimization with decoupled weight decay

17. Gradient Descent with Momentum

Momentum uses information from previous gradients to help smooth the optimization trajectory.

vₜ = βvₜ₋₁ + (1 − β)∇L
θₜ₊₁ = θₜ − ηvₜ

Here, θ represents model parameters.

Momentum can help reduce oscillation and accelerate movement in consistent directions.

18. AdaGrad

AdaGrad adapts the learning rate separately for each parameter based on the history of squared gradients.

A simplified form is:

Gₜ = Gₜ₋₁ + gₜ²
θₜ₊₁ = θₜ − η / (√Gₜ + ε) × gₜ

A limitation is that the accumulated squared gradients can continually grow, making the effective learning rate become very small.

19. RMSprop

RMSprop modifies the AdaGrad idea by using an exponentially weighted moving average of squared gradients.
vₜ = βvₜ₋₁ + (1 − β)gₜ²
θₜ₊₁ = θₜ − η / (√vₜ + ε) × gₜ

This prevents the denominator from accumulating all historical squared gradients indefinitely.

20. Adam Optimizer

Adam stands for Adaptive Moment Estimation. It tracks both the first moment and second moment of gradients.

First moment:

mₜ = β₁mₜ₋₁ + (1 − β₁)gₜ

Second moment:

vₜ = β₂vₜ₋₁ + (1 − β₂)gₜ²

Bias-corrected moments:

m̂ₜ = mₜ / (1 − β₁ᵗ)
v̂ₜ = vₜ / (1 − β₂ᵗ)

Parameter update:

θₜ₊₁ = θₜ − η × m̂ₜ / (√v̂ₜ + ε)
Adam is widely used because it automatically adapts the effective update size for different parameters and often provides a convenient starting point for neural-network training.

21. AdamW

AdamW is an Adam-based optimizer that uses decoupled weight decay. It is widely used in modern deep-learning training, particularly in many transformer-based models.

The important conceptual difference is that weight decay is handled separately from the adaptive gradient update.

23. Gradient Descent vs Backpropagation vs Optimizer

Concept What It Does
Forward Propagation Calculates the network prediction
Loss Function Measures prediction error
Backpropagation Calculates gradients of the loss with respect to parameters
Gradient Descent Uses gradients to move parameters toward lower loss
Optimizer Implements a parameter-update strategy, often improving basic gradient descent

24. Easy Way to Remember

Bias: Helps shift a neuron's activation.

Gradient: Tells us how the loss changes with respect to a parameter.

Backpropagation: Calculates the gradients.

Gradient Descent: Moves parameters in the direction that reduces loss.

Optimizer: Determines how those gradients are used to update parameters.
