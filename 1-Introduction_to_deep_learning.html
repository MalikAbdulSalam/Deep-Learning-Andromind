2. What is Artificial Intelligence?

Artificial Intelligence (AI) is a field of computer science that focuses on building machines and software capable of performing tasks that normally require human intelligence.

Examples of AI

  • Understanding speech
  • Recognizing images
  • Making decisions
  • Understanding language
  • Predicting outcomes
  • Planning routes
  • Playing games
  • Controlling robots
Simple Definition:
AI is the broader field of making machines intelligent.
Camera ↓ AI System ↓ Understand Environment ↓ Make Decision ↓ Take Action

3. What is Machine Learning?

Machine Learning is a subset of Artificial Intelligence in which computers learn patterns from data and use those patterns to make predictions or decisions.

Traditional Programming

Rules + Data ↓ Program ↓ Output

For example, a spam filter could use manually created rules:

IF email contains "FREE"
AND email contains "WIN"
THEN spam

Machine Learning Approach

Data + Expected Output ↓ Machine Learning Algorithm ↓ Learned Model ↓ Prediction

4. What is Deep Learning?

Deep Learning is a subfield of Machine Learning that primarily uses artificial neural networks containing multiple layers.

Artificial Intelligence │ ↓ Machine Learning │ ↓ Deep Learning
Important: AI is the broader field. Machine Learning is a subset of AI, while Deep Learning is a subset of Machine Learning.

5. Why is it Called "Deep" Learning?

The term deep refers to the use of multiple layers in a neural network.

Input Layer ↓ Hidden Layer 1 ↓ Hidden Layer 2 ↓ Hidden Layer 3 ↓ Hidden Layer 4 ↓ Output Layer

A network with more layers can learn increasingly complex representations of the input data.

6. Traditional Machine Learning vs Deep Learning

Traditional Machine Learning

Raw Data ↓ Feature Engineering ↓ ML Algorithm ↓ Prediction

Deep Learning

Raw Data ↓ Neural Network ↓ Feature Learning ↓ Prediction

One important advantage of Deep Learning is that the neural network can learn useful representations directly from raw data.

7. Example: Image Recognition

Suppose we want to identify whether an image contains a cat or a dog.

Traditional Approach

Image ↓ Extract Edges ↓ Extract Texture ↓ Extract Shape ↓ Machine Learning Algorithm ↓ Cat / Dog

Deep Learning Approach

Image ↓ Neural Network ↓ Low-Level Features ↓ Mid-Level Features ↓ High-Level Features ↓ Cat / Dog

8. Artificial Neural Network

The basic building block of many Deep Learning systems is the Artificial Neural Network (ANN).

Input Layer ↓ Hidden Layer(s) ↓ Output Layer

Neural networks are mathematical models inspired loosely by biological neural networks.

9. Artificial Neuron

An artificial neuron receives inputs, multiplies them by weights, adds a bias, and passes the result through an activation function.

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
y = f(z)

Where:

  • x = input
  • w = weight
  • b = bias
  • f = activation function
  • y = output
Inputs ↓ Weighted Sum ↓ Bias ↓ Activation Function ↓ Output

10. Weights

Weights determine the importance of different inputs.

y = w₁x₁ + w₂x₂

If a weight has a larger magnitude, the corresponding input can have a stronger influence on the output.

During training, the neural network adjusts its weights to reduce prediction error.

11. Bias

Bias provides an additional parameter that allows the neuron to shift its activation.

z = wx + b

12. Activation Functions

An activation function determines the output of a neuron after applying the weighted sum and bias.

12.1 Sigmoid

σ(x) = 1 / (1 + e-x)

Output range: 0 ≤ σ(x) ≤ 1

12.2 ReLU

ReLU(x) = max(0, x) 
x < 0  →  0
x > 0  →  x

ReLU is widely used in hidden layers of neural networks.

12.3 Softmax

Softmax is commonly used for multi-class classification. 

Cat     → 0.80
Dog     → 0.15
Horse   → 0.05

The probabilities sum to approximately 1.

13. How Does Deep Learning Learn?

A neural network starts with parameters that generally do not produce accurate predictions. During training, the network repeatedly adjusts these parameters.

Input Data ↓ Forward Propagation ↓ Prediction ↓ Loss Calculation ↓ Backpropagation ↓ Update Weights ↓ Repeat

14. Loss Function

A loss function measures how different the model's prediction is from the actual target.

Loss = Difference(Prediction, Actual)

Common Loss Functions

  • Mean Squared Error (MSE)
  • Binary Cross-Entropy
  • Categorical Cross-Entropy

15. Backpropagation

Backpropagation is a fundamental algorithm used to calculate how the network's parameters contributed to the prediction error.

Prediction ↓ Calculate Loss ↓ Calculate Gradients ↓ Propagate Error Backward ↓ Update Weights

Backpropagation is normally used together with an optimization algorithm such as Gradient Descent.

16. Gradient Descent

Gradient Descent is an optimization method used to minimize the loss function by updating model parameters.

High Loss ↓ Adjust Parameters ↓ Lower Loss ↓ Adjust Parameters ↓ Even Lower Loss
wnew = wold − η (∂L / ∂w)

Where:

  • w = weight
  • L = loss
  • η = learning rate

17. Why Did Deep Learning Become Popular?

Large Datasets

Modern systems generate huge amounts of images, videos, text, audio, sensor and other data.

Powerful Hardware

GPUs made large-scale neural-network training much more practical.

Better Algorithms

Advances in optimization, architectures, regularization and normalization improved training.

Open-Source Frameworks

Frameworks such as TensorFlow, PyTorch and Keras simplified Deep Learning development.

21. Training, Validation and Testing

Training Set

Used to learn the model's parameters.

Validation Set

Used to tune the model and select configurations.

Test Set

Used for final evaluation of the trained model.

Dataset │ ├── Training Data │ ├── Validation Data │ └── Testing Data

22. Overfitting

Overfitting occurs when a model learns the training data too specifically and performs poorly on unseen data.

Example:
Training Accuracy = 99%
Testing Accuracy = 70%

Common Solutions

  • More training data
  • Data augmentation
  • Dropout
  • Regularization
  • Early stopping
  • Transfer learning

23. Underfitting

Underfitting occurs when a model is too simple or has not learned enough from the available data.

Example:
Training Accuracy = 65%
Testing Accuracy = 63%

25. Important Deep Learning Terminology

Term Meaning
Dataset Collection of data used for learning.
Feature An input variable or measurable characteristic.
Label The target or expected output.
Model A mathematical representation learned from data.
Parameter A value learned by the model, such as a weight.
Hyperparameter A setting chosen by the practitioner.
Epoch One complete pass through the training dataset.
Batch A subset of training examples processed together.
Learning Rate Controls the size of parameter updates.
Loss Measures prediction error.

27. Key Takeaways

1. AI is the broad field of creating intelligent systems.

2. Machine Learning is a subset of AI that learns from data.

3. Deep Learning is a subset of Machine Learning based primarily on multi-layer neural networks.

4. Deep Learning can automatically learn useful representations from raw data.

5. Deep Learning is especially powerful for complex data such as images, video, audio, text, and sequential information.
