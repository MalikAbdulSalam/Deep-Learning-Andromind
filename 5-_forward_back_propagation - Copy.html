How Neural Networks Work: Perceptron, ANN & Backpropagation

1. What is a Neural Network?

A neural network is a computational model made of interconnected artificial neurons. The neurons process input data using weights, biases and activation functions to produce an output.

The basic idea is:

Input Data ↓ Weighted Calculations ↓ Activation Functions ↓ Prediction ↓ Loss / Error ↓ Backpropagation ↓ Update Weights ↓ Better Prediction

2. How Does a Perceptron Work?

A perceptron is one of the simplest neural-network models. It takes input values, multiplies them by weights, adds a bias, and produces an output using an activation function.
x₁ ──► w₁ ──┐ │ x₂ ──► w₂ ──┤ ├──► Σ + b ──► Activation ──► Output │ x₃ ──► w₃ ──┤ │ xₙ ──► wₙ ──┘

The weighted sum is:

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

The output is:

y = f(z)

In the traditional perceptron, f(z) is usually a step/threshold function.

3. Simple Perceptron Example

Suppose we want to predict whether a student passes based on study hours and attendance.

Input Meaning
x₁ Study Hours
x₂ Attendance

Suppose:

x₁ = 5
x₂ = 8
w₁ = 0.6
w₂ = 0.4
b = -5

Calculate:

z = (5 × 0.6) + (8 × 0.4) - 5
z = 3 + 3.2 - 5
z = 1.2

Since z > 0, the step function produces:

Output = 1
The perceptron therefore predicts the positive class.

4. How Does a Perceptron Learn?

A perceptron starts with initial weights. It then makes predictions and compares those predictions with the correct target values.

Input ↓ Calculate Weighted Sum ↓ Activation ↓ Prediction ↓ Compare with Target ↓ Calculate Error ↓ Update Weights ↓ Next Training Example

5. Perceptron Learning Rule

A classical perceptron can update its weights using:

wᵢ(new) = wᵢ(old) + η × (target - prediction) × xᵢ

The bias can be updated as:

b(new) = b(old) + η × (target - prediction)

Where:

  • η = learning rate
  • target = correct answer
  • prediction = model prediction
  • xᵢ = input feature

6. Backpropagation in a Perceptron

Important distinction: In a single traditional perceptron, we usually describe learning using the perceptron learning rule rather than modern backpropagation. Backpropagation becomes especially important for multilayer neural networks.

Conceptually, however, the idea is similar:

Prediction ↓ Error ↓ Determine how weights contributed to error ↓ Update weights ↓ Better prediction

Modern gradient-based training requires differentiable operations. A hard threshold activation is not suitable for ordinary gradient-based backpropagation because its derivative is zero almost everywhere.

7. What is an Artificial Neural Network (ANN)?

An Artificial Neural Network (ANN) is a network of interconnected artificial neurons arranged into layers.

A typical ANN contains:

  • Input Layer
  • One or more Hidden Layers
  • Output Layer
Input Layer ↓ Hidden Layer 1 ↓ Hidden Layer 2 ↓ Output Layer

8. Example of an ANN

x₁ ──┐ x₂ ──┼──► ○ ──┐ x₃ ──┘ │ ├──► ○ ──► Output x₄ ─────────► ○ ──┘ │ └──► ○

Every connection has a weight, and every neuron may have a bias. Hidden neurons normally use nonlinear activation functions.

9. Forward Propagation in an ANN

The first phase of neural-network training is called forward propagation or forward pass.

Step 1: Input data enters the input layer.
Step 2: Each neuron calculates a weighted sum.
Step 3: The activation function is applied.
Step 4: The result is passed to the next layer.
Step 5: The output layer produces the prediction.
z = Wx + b
a = f(z)

Here a is the activation/output of a layer.

10. Loss Function

After the ANN produces a prediction, the prediction is compared with the actual target.

Actual Target │ │ ▼ Compare ▲ │ Prediction │ ▼ Loss

The loss function measures how far the prediction is from the desired target.

Example: Mean Squared Error

MSE = (1/n) Σ(y - ŷ)²

Where:

  • y = actual target
  • ŷ = predicted value
  • n = number of samples

11. What is Backpropagation?

Backpropagation is an algorithm used to calculate how much each trainable parameter contributed to the network's loss. These gradients are then used by an optimizer to update the weights and biases.

Backpropagation works backward through the network, starting from the output layer and moving toward the input layer.

Forward Pass ──────────────────────────────► Input → Hidden → Hidden → Output ↓ Loss Backward Pass ◄────────────────────────────── Input ← Hidden ← Hidden ← Output

12. Four Main Steps of ANN Training

1. Forward Propagation
Calculate the prediction using the current weights.
2. Calculate Loss
Measure the difference between prediction and target.
3. Backpropagation
Calculate gradients of the loss with respect to weights and biases.
4. Update Parameters
The optimizer updates the weights and biases.

13. Gradient Descent

After backpropagation calculates the gradients, an optimizer such as gradient descent uses them to update the parameters.

w(new) = w(old) − η × ∂L/∂w
b(new) = b(old) − η × ∂L/∂b

Where:

  • L = loss
  • η = learning rate
  • ∂L/∂w = gradient of loss with respect to weight
  • ∂L/∂b = gradient of loss with respect to bias

14. Chain Rule in Backpropagation

The mathematical foundation of backpropagation is the chain rule of calculus.

Suppose:

L → a → z → w

Then the gradient can be calculated as:

∂L/∂w = ∂L/∂a × ∂a/∂z × ∂z/∂w

This allows the network to determine how a small change in a particular weight would affect the final loss.

15. Simple Backpropagation Example

Consider a very small neural network:

Input │ ▼ Hidden Neuron │ ▼ Output Neuron │ ▼ Prediction │ ▼ Loss

Suppose the network predicts:

ŷ = 0.7

But the actual target is:

y = 1.0

The network has an error. The loss function calculates how large that error is.

Loss = (1.0 - 0.7)²
Loss = 0.09

Backpropagation then calculates gradients for the output weight and hidden-layer weights.

The optimizer uses those gradients to modify the weights so that future predictions move closer to the target.

16. Neural Network Training is Repeated

┌──────────────────────┐ │ │ ▼ │ Input → Forward Pass → Prediction │ ↓ │ Loss │ ↓ │ Backpropagation │ ↓ │ Gradient Calculation │ ↓ │ Update Weights ───────┘

This process is repeated many times over the training data.

One complete pass through the entire training dataset is called an epoch.

17. Perceptron vs ANN

Feature Perceptron ANN
Structure Usually a single computational layer Input, hidden and output layers
Neurons Simple neurons Many interconnected neurons
Activation Traditionally step function ReLU, sigmoid, tanh, softmax, etc.
Learning Perceptron learning rule Backpropagation + optimizer
Nonlinear Problems Limited Can model complex nonlinear relationships
Hidden Layers No Can have one or many
Typical Capability Simple classification Complex classification and regression

18. Perceptron Learning Rule vs Backpropagation

Feature Perceptron Learning Rule Backpropagation
Used mainly for Single-layer perceptron Multilayer neural networks
Basic idea Correct weights based on prediction error Calculate gradients through the network
Calculus Does not require the modern chain-rule gradient procedure Uses chain rule
Activation Traditionally step Usually differentiable activations
Hidden layers No Yes
Complexity Simple Much more general

TRAINING DATA │ ▼ ┌─────────────┐ │ Forward │ │ Propagation │ └─────────────┘ │ ▼ Prediction │ ▼ ┌─────────────┐ │ Loss │ │ Function │ └─────────────┘ │ ▼ ┌─────────────┐ │ Backprop │ │ agation │ └─────────────┘ │ ▼ Gradients │ ▼ ┌─────────────┐ │ Optimizer │ └─────────────┘ │ ▼ Updated Weights │ └──────────► Repeat

20. Important Terminology

Term Meaning
Weight Learnable parameter controlling the contribution of an input
Bias Learnable parameter that shifts the activation
Activation Function Transforms a neuron's weighted sum
Forward Propagation Computing predictions from inputs
Loss Function Measures prediction error
Backpropagation Computes gradients of loss with respect to model parameters
Gradient Indicates how the loss changes with a parameter
Optimizer Uses gradients to update model parameters
Learning Rate Controls the size of parameter updates
Epoch One complete pass through the training dataset

21. Easy Way to Remember

Perceptron

Input → Weighted Sum → Activation → Prediction → Error → Weight Update

ANN

Input → Forward Pass → Prediction → Loss → Backpropagation → Gradients → Optimizer → Updated Weights

22. Final Concept

NEURAL NETWORK TRAINING │ ▼ Forward Pass │ ▼ Prediction │ ▼ Loss │ ▼ Backpropagation │ ▼ Gradients │ ▼ Optimizer │ ▼ Updated Weights │ ▼ Repeat
Key Idea: Backpropagation does not itself "update" the weights. It calculates the gradients that tell us how the loss changes with respect to the weights and biases. An optimizer such as gradient descent then uses those gradients to update the parameters.
