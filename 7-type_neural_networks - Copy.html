Types of Neural Network Architectures

Learning Objective: After this lesson, you will understand the major types of neural networks, their architectures, how they process data, and where each architecture is commonly used.

1. What is a Neural Network Architecture?

A neural network architecture describes how neurons are organized and how information flows between them.

Different types of data require different ways of processing information. For example:

  • Images contain spatial patterns.
  • Videos contain spatial and temporal patterns.
  • Text contains sequential relationships.
  • Graphs contain relationships between connected entities.

Therefore, different neural network architectures have been developed for different types of problems.

2. Basic Neural Network Architecture

The simplest neural network consists of:

  • Input Layer
  • One or more Hidden Layers
  • Output Layer
Input Layer Hidden Layer Output Layer x₁ ───────────► ● │ x₂ ───────────► ● ───────────► ● │ x₃ ───────────► ●

The information normally flows from the input toward the output. This type of network is called a Feedforward Neural Network.

3. Major Types of Neural Networks

The major neural network architectures include:

Perceptron Feedforward NN MLP CNN RNN LSTM GRU Autoencoder GAN Transformer GNN Siamese Network Residual Network

4. Perceptron

The Perceptron is one of the simplest neural network architectures. It contains a single computational layer.

Inputs Weighted Sum Output x₁ ───────► x₂ ───────► Σ(wᵢxᵢ) + b ───────► Activation ───────► y x₃ ───────►
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

Traditionally, the perceptron uses a threshold activation function.

Applications

  • Simple binary classification
  • Basic logic gates such as AND and OR
  • Understanding neural network fundamentals
Limitation: A single perceptron cannot solve non-linearly separable problems such as XOR.

5. Feedforward Neural Network

In a Feedforward Neural Network (FNN), information moves in one direction: from input to hidden layers and finally to the output.

Input Layer Hidden Layer 1 Hidden Layer 2 Output x₁ ───────► ● ───────────► ● x₂ ───────► ● ───────────► ● ───────────► ● x₃ ───────► ● ───────────► ●

There are no feedback connections in a basic feedforward network.

Applications

  • Classification
  • Regression
  • Tabular data
  • Pattern recognition

6. Multi-Layer Perceptron (MLP)

An MLP is a feedforward neural network containing one or more hidden layers.

Input Hidden Layers Output ● ───────────────► ● ───────────────► ● ● ───────────────► ● ───────────────► ● ─────────► ● ● ───────────────► ● ───────────────► ●

Each neuron typically performs:

z = Σ(wᵢxᵢ) + b
a = f(z)

where:

  • w = weight
  • x = input
  • b = bias
  • f = activation function
  • a = activated output

Applications

  • Classification
  • Regression
  • Fraud detection
  • Prediction problems

7. Convolutional Neural Network (CNN)

A Convolutional Neural Network is particularly designed for data with spatial structure, especially images.

Image │ ▼ Convolution │ ▼ Activation │ ▼ Pooling │ ▼ Convolution │ ▼ Pooling │ ▼ Flatten │ ▼ Fully Connected Layer │ ▼ Output

Important CNN Components

  • Convolution: extracts local features.
  • Activation: introduces non-linearity.
  • Pooling: reduces spatial dimensions.
  • Flatten: converts feature maps into a vector.
  • Fully Connected Layer: performs final prediction.

CNN Learns Hierarchical Features

Early Layers ↓ Edges ↓ Corners / Textures ↓ Shapes ↓ Object Parts ↓ Complete Object

Applications

  • Image classification
  • Object detection
  • Image segmentation
  • Face recognition
  • Medical image analysis
  • Satellite image analysis

Examples of CNN-based architectures include LeNet, AlexNet, VGG, Inception, ResNet and EfficientNet.

8. Recurrent Neural Network (RNN)

An RNN is designed for sequential data. Unlike a basic feedforward network, an RNN maintains information from previous time steps.

x₁ ──► [RNN] ──► h₁ │ ▼ x₂ ──► [RNN] ──► h₂ │ ▼ x₃ ──► [RNN] ──► h₃ │ ▼ x₄ ──► [RNN] ──► h₄

The hidden state carries information from previous steps.

hₜ = f(Wₓxₜ + Wₕhₜ₋₁ + b)

Applications

  • Time-series prediction
  • Speech processing
  • Text processing
  • Sequence classification
Problem: Basic RNNs can suffer from vanishing and exploding gradients when learning long-term dependencies.

9. Long Short-Term Memory (LSTM)

LSTM is a special type of recurrent neural network designed to handle long-term dependencies better than a basic RNN.

Previous State │ ▼ ┌─────────────┐ │ LSTM │ │ │ │ Forget Gate │ │ Input Gate │ │ Output Gate │ └─────────────┘ │ ▼ New Hidden State

LSTM Gates

Gate Purpose
Forget Gate Decides what information should be removed.
Input Gate Decides what new information should be stored.
Output Gate Controls what information becomes the output.

Applications

  • Time-series forecasting
  • Speech recognition
  • Language modeling
  • Sequence prediction

10. Gated Recurrent Unit (GRU)

A GRU is another recurrent architecture designed to handle long-term dependencies.

GRU is generally simpler than LSTM and uses fewer gates.

Input Sequence │ ▼ ┌──────────┐ │ GRU │ │ │ │ Update │ │ Reset │ │ Gates │ └──────────┘ │ ▼ Output Sequence

Applications

  • Speech processing
  • Time-series prediction
  • Text processing
  • Sequence classification

11. Autoencoder

An Autoencoder is a neural network that learns to represent input data in a compressed form and reconstruct the original input.

Input │ ▼ Encoder │ ▼ Latent Representation │ ▼ Decoder │ ▼ Reconstructed Input

The architecture has three major components:

  • Encoder: compresses the input.
  • Latent Space: compact representation.
  • Decoder: reconstructs the input.

Applications

  • Dimensionality reduction
  • Denoising
  • Anomaly detection
  • Feature learning
  • Data compression

12. Variational Autoencoder (VAE)

A Variational Autoencoder is a generative version of an autoencoder that learns a probability distribution in latent space.

Input │ ▼ Encoder │ ├────► Mean (μ) │ └────► Variance (σ) │ ▼ Latent Sample │ ▼ Decoder │ ▼ New Data

Applications

  • Generative modeling
  • Image generation
  • Data representation
  • Data synthesis

13. Generative Adversarial Network (GAN)

A GAN consists of two neural networks competing with each other:

  • Generator
  • Discriminator
Random Noise │ ▼ Generator │ ▼ Fake Data ──────────┐ ▼ Discriminator ▲ │ Real Data ──────────┘ │ ▼ Real / Fake

Generator

The generator creates synthetic data that attempts to resemble real data.

Discriminator

The discriminator attempts to distinguish real data from generated data.

Applications

  • Image generation
  • Image-to-image translation
  • Super-resolution
  • Data augmentation
  • Image synthesis

14. Transformer Neural Network

The Transformer architecture was introduced for sequence processing and is based primarily on attention mechanisms rather than recurrence.

Input Tokens │ ▼ Embedding │ ▼ Positional Information │ ▼ Self-Attention │ ▼ Feedforward Network │ ▼ Output

Self-Attention

Self-attention allows the model to determine which parts of the input sequence are important when processing a particular token.

Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V

where:

  • Q = Query
  • K = Key
  • V = Value
  • dₖ = dimension of the key vectors

Applications

  • Natural Language Processing
  • Machine translation
  • Text generation
  • Large Language Models
  • Computer vision
  • Multimodal AI

15. Graph Neural Network (GNN)

A Graph Neural Network is designed for graph-structured data. A graph consists of:

  • Nodes
  • Edges
  • Node or edge features
Node A / \ / \ Node B ─── Node C \ / \ / Node D Nodes = Entities Edges = Relationships

GNNs aggregate information from neighboring nodes to learn representations.

Applications

  • Social network analysis
  • Recommendation systems
  • Fraud detection
  • Drug discovery
  • Traffic networks
  • Knowledge graphs

16. Siamese Neural Network

A Siamese Network contains two or more branches that share the same parameters.

Image A ──► Network ──► Feature A ──┐ ├──► Similarity Image B ──► Network ──► Feature B ──┘

Instead of directly classifying an image, the network can learn whether two inputs are similar or different.

Applications

  • Face verification
  • Signature verification
  • Image matching
  • One-shot learning
  • Similarity search

17. Residual Neural Network (ResNet)

A Residual Network introduces shortcut connections that allow information to bypass one or more layers.

Input x │ ├──────────────────────┐ │ │ ▼ │ Layer 1 │ │ │ Layer 2 │ │ │ └──────► F(x) ─────────┤ ▼ F(x) + x │ ▼ Output

The fundamental idea is the residual mapping:

Output = F(x) + x

Shortcut connections help very deep networks learn effectively and help mitigate degradation problems associated with simply stacking many layers.

Applications

  • Image classification
  • Object detection
  • Image segmentation
  • Computer vision feature extraction

18. U-Net

U-Net is a popular encoder-decoder architecture, especially for image segmentation.

Encoder │ ┌────────┴────────┐ ▼ │ Down │ ▼ │ Down │ ▼ │ Bottleneck │ │ │ ▼ │ Up ◄──── Skip Connection │ ▼ Up ◄──── Skip Connection │ ▼ Segmentation Mask

Applications

  • Medical image segmentation
  • Satellite image segmentation
  • Road segmentation
  • Object segmentation
  • Industrial image segmentation

22. Important Concept: Architecture vs Model

The terms architecture and model are related but should not always be treated as exactly the same thing.

Architecture describes the design of a neural network: layers, connections, operations, attention, convolution, recurrence, etc.
Model usually refers to a particular implementation of an architecture together with its learned parameters (weights).

For example:

ResNet → architecture family
ResNet-50 → a particular architecture configuration
Trained ResNet-50 weights → learned model parameters

25. Key Points

  • Perceptron is one of the simplest neural networks.
  • MLP uses multiple fully connected layers.
  • CNN is highly useful for spatial data such as images.
  • RNN processes sequential information using recurrent hidden states.
  • LSTM and GRU improve handling of longer dependencies.
  • Autoencoders learn compact representations and reconstruction.
  • GANs use a generator and discriminator for adversarial generation.
  • Transformers use attention to model relationships between tokens or other elements.
  • GNNs process graph-structured data.
  • Siamese networks are useful for learning similarity.
  • ResNet uses shortcut connections to enable very deep networks.
  • U-Net is widely used for segmentation.

26. Final Summary

There is no single neural network architecture that is ideal for every problem. The architecture should be selected according to the structure of the data and the task.

Images → CNN / Vision Transformer

Sequences → RNN / LSTM / GRU / Transformer

Text → Transformer

Graphs → GNN

Similarity → Siamese Network

Compression / Representation → Autoencoder

Generation → GAN / VAE / other generative architectures

Segmentation → U-Net / related encoder-decoder architectures
