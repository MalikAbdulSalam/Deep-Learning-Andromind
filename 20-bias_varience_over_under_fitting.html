1. Why Do We Need These Concepts?

When we train a machine learning model, our objective is not simply to memorize the training data.

We want the model to learn useful patterns that allow it to make accurate predictions on new, unseen data.

Training Data
↓
Machine Learning Model
↓
Learned Pattern
↓
New / Unseen Data
↓
Good Prediction
A model that performs extremely well on training data can still perform poorly on new data. This is one of the main reasons we study bias, variance, overfitting and underfitting.

2. What is Model Generalization?

Generalization means that a model can perform well not only on training data but also on previously unseen data.

Training Data
↓
Model learns patterns
↓
Unseen Data
↓
Accurate Predictions

A good machine learning model should learn the underlying pattern, rather than simply memorizing individual training examples.

3. Bias

Bias is the error introduced when a model makes overly simplistic assumptions about the underlying relationship in the data.

A model with high bias is usually too simple to capture the important patterns in the data.

Example

Suppose the real relationship between house size and price is complex.

But we use an extremely simple model: 


Price = w × Area + b

If the actual relationship is much more complicated, the simple model may fail to capture it.

High Bias → Model is usually too simple

4. Variance

Variance describes how much a model's predictions change when the training dataset changes.

A high-variance model is very sensitive to the particular training examples it sees.

It may learn not only useful patterns but also noise and random fluctuations in the training data.

High Variance → Model is usually too sensitive to training data

5. Variance Mathematical Concept

Variance measures how far values are spread around their mean. 


Var(X) = E[(X - μ)²]

Another common representation is: 


Var(X) = E(X²) - [E(X)]²

In machine learning, the idea is that a high-variance model can change substantially when the training data changes.

The important machine-learning interpretation is:

High variance = strong dependence on the training dataset.

6. Underfitting

Underfitting occurs when a model is too simple to learn the important patterns in the data.

Data
↓
Too Simple Model
↓
Poor Training Performance
↓
Poor Testing Performance

Typical Characteristics

Training Error Validation/Test Error Typical Interpretation
High High Underfitting

Example

Imagine trying to predict house prices using only: 


Price = Area × Constant

The model may ignore:

  • Location
  • Bedrooms
  • Bathrooms
  • Age
  • Construction quality

Therefore, the model may be too simple.

7. Causes of Underfitting

  • Model is too simple
  • Too few features
  • Insufficient training
  • Excessive regularization
  • Model has too few layers
  • Model has too few neurons
  • Features do not represent the problem well

8. How to Reduce Underfitting

  • Use a more powerful model
  • Add useful features
  • Increase model complexity
  • Train for more epochs
  • Reduce excessive regularization
  • Improve feature engineering

9. Overfitting

Overfitting occurs when a model learns the training data too closely, including noise or accidental patterns.

Training Data
↓
Very Complex Model
↓
Training Error Very Low
↓
Test Error High

Typical Characteristics

Training Error Validation/Test Error Typical Interpretation
Very Low High Overfitting

10. Real-World Example of Overfitting

Imagine a student preparing for an exam.

The student memorizes every question from the practice paper.

On exactly the same questions: 


Score = 100%

But when the teacher gives new questions: 


Score = 50%

The student memorized the examples instead of learning the underlying concepts.

This is similar to overfitting in machine learning.

11. Causes of Overfitting

  • Model is too complex
  • Too many parameters
  • Small training dataset
  • Training for too many epochs
  • Too many neural-network layers
  • Too many neurons
  • Noise in the training data
  • Insufficient regularization

12. How to Reduce Overfitting

  • Collect more training data
  • Use data augmentation
  • Use dropout
  • Use L1/L2 regularization
  • Reduce model complexity
  • Use early stopping
  • Remove irrelevant features
  • Use cross-validation where appropriate

13. Underfitting vs Overfitting

Property Underfitting Good Fit Overfitting
Model Complexity Too Low Appropriate Too High
Training Error High Low Very Low
Test Error High Low High
Bias High Low Low
Variance Low Moderate High

14. Bias-Variance Tradeoff

Machine learning often involves balancing bias and variance.

High Bias ← Good Balance → High Variance

A very simple model may have: 


High Bias
Low Variance

A very complex model may have: 


Low Bias
High Variance

We want a model that provides a useful balance.

15. Total Prediction Error

A common conceptual decomposition of expected prediction error is: 


Total Error ≈ Bias² + Variance + Irreducible Noise

The three components are:

Component Meaning
Bias² Error from overly simplistic assumptions
Variance Error from sensitivity to the training data
Irreducible Noise Random variation that cannot be completely eliminated

16. Model Complexity

Model complexity describes how flexible a model is.

Simple Model
→
Moderate Model
→
Complex Model

As model complexity increases: 


Bias usually decreases

Variance usually increases

Therefore, increasing complexity does not automatically make a model better.

17. Training Error and Validation Error

One of the easiest ways to detect overfitting is to monitor training and validation performance.

Training Dataset
→
Model
→
Training Error

Validation Dataset
→
Model
→
Validation Error

Typical Overfitting Pattern 


Epoch      Training Loss      Validation Loss

1              High                High
10             ↓                   ↓
20             ↓                   ↓
30             ↓                   ↓
40             ↓                   Lowest
50             ↓                   Starts increasing
60             ↓                   Higher
70             ↓                   Higher
80             Very Low            Very High
If training loss continues decreasing while validation loss starts increasing, this is a common sign that the model is overfitting.

18. Early Stopping

Early stopping is a technique used to stop training when validation performance stops improving.

Training
↓
Validation Loss Improves
↓
Validation Loss Stops Improving
↓
Stop Training

Instead of training for an unnecessarily large number of epochs, we keep the model from continuing into a region where validation performance is getting worse.

19. Dropout

Dropout is a regularization technique commonly used in neural networks.

During training, dropout randomly disables some neurons. 


Input
  ↓
Linear Layer
  ↓
ReLU
  ↓
Dropout
  ↓
Linear Layer
  ↓
Output

PyTorch Example 

self.network = nn.Sequential(

    nn.Linear(10, 64),

    nn.ReLU(),

    nn.Dropout(0.3),

    nn.Linear(64, 32),

    nn.ReLU(),

    nn.Dropout(0.3),

    nn.Linear(32, 1)
)

A dropout value of 0.3 means that approximately 30% of the eligible activations are randomly dropped during training.

20. L2 Regularization / Weight Decay

Another common method of controlling overfitting is regularization.

With the Adam optimizer, weight decay can be used: 

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001,
    weight_decay=0.0001
)

Weight decay discourages excessively large weights and can help control model complexity.

21. Data Augmentation

Data augmentation creates additional training examples by applying suitable transformations.

It is particularly common in computer vision.

Example 


Original Image
      ↓
Resize
      ↓
Flip
      ↓
Rotate
      ↓
Crop
      ↓
Brightness Change
      ↓
More Training Examples

More diverse training examples can help a model generalize better.

22. More Training Data

A model trained on a very small dataset can easily memorize the training examples.

Increasing the amount and diversity of high-quality training data can help reduce this problem.

More representative data generally gives the model more information from which to learn general patterns.

23. Neural Network Example of Overfitting

Consider a neural network for image classification. 


Input Image
     ↓
Conv Layer
     ↓
Conv Layer
     ↓
Conv Layer
     ↓
Many Fully Connected Layers
     ↓
Output

If the dataset contains only a small number of images while the network has millions of parameters, the model may have enough capacity to memorize the training examples.

Possible solutions include:

  • More training images
  • Data augmentation
  • Dropout
  • Weight decay
  • Transfer learning
  • Early stopping

24. PyTorch Demonstration

The following example demonstrates how model complexity can affect training and validation performance.

Import Libraries 

import torch
import torch.nn as nn
import torch.optim as optim

import numpy as np
import matplotlib.pyplot as plt

25. Create Synthetic Data 

np.random.seed(42)

X = np.linspace(
    -3,
    3,
    100
)

y = (
    np.sin(X)
    + 0.2 * np.random.randn(100)
)

Here we create data based on a nonlinear function: 


y = sin(x) + noise

26. Convert Data to PyTorch Tensors 

X = torch.tensor(
    X,
    dtype=torch.float32
).view(-1, 1)

y = torch.tensor(
    y,
    dtype=torch.float32
).view(-1, 1)

27. Split Training and Validation Data 

train_size = 80

X_train = X[:train_size]
y_train = y[:train_size]

X_val = X[train_size:]
y_val = y[train_size:]

28. Build a Neural Network 

class RegressionModel(nn.Module):

    def __init__(self):

        super().__init__()

        self.network = nn.Sequential(

            nn.Linear(1, 64),

            nn.ReLU(),

            nn.Linear(64, 64),

            nn.ReLU(),

            nn.Linear(64, 64),

            nn.ReLU(),

            nn.Linear(64, 1)
        )

    def forward(self, x):

        return self.network(x)

29. Create Model, Loss and Optimizer 

model = RegressionModel()

criterion = nn.MSELoss()

optimizer = optim.Adam(
    model.parameters(),
    lr=0.001
)

30. Training with Validation Loss 

epochs = 1000

train_losses = []
val_losses = []

for epoch in range(epochs):

    # Training mode
    model.train()

    # Forward pass
    train_prediction = model(X_train)

    # Training loss
    train_loss = criterion(
        train_prediction,
        y_train
    )

    # Clear gradients
    optimizer.zero_grad()

    # Backpropagation
    train_loss.backward()

    # Update weights
    optimizer.step()


    # Validation
    model.eval()

    with torch.no_grad():

        val_prediction = model(X_val)

        val_loss = criterion(
            val_prediction,
            y_val
        )


    train_losses.append(
        train_loss.item()
    )

    val_losses.append(
        val_loss.item()
    )


    if (epoch + 1) % 100 == 0:

        print(
            f"Epoch: {epoch+1}, "
            f"Train Loss: {train_loss.item():.4f}, "
            f"Validation Loss: {val_loss.item():.4f}"
        )

31. Plot Training and Validation Loss 

plt.figure(figsize=(10, 6))

plt.plot(
    train_losses,
    label="Training Loss"
)

plt.plot(
    val_losses,
    label="Validation Loss"
)

plt.xlabel("Epoch")

plt.ylabel("MSE Loss")

plt.title(
    "Training vs Validation Loss"
)

plt.legend()

plt.show()

32. How to Read the Loss Graph

Case 1 — Underfitting 


Training Loss     High
Validation Loss   High

The model has not learned enough of the underlying pattern.

Case 2 — Good Fit 


Training Loss     Low
Validation Loss   Low

Both improve and remain reasonably close.

Case 3 — Overfitting 


Training Loss     ↓ continues decreasing

Validation Loss  ↓ initially decreases
                  ↑ then starts increasing
The gap between training and validation performance is an important diagnostic signal.

47. Final Summary

Bias represents error from overly simple assumptions.

Variance represents sensitivity to the particular training data.

Underfitting happens when the model is too simple to learn the important patterns.

Overfitting happens when the model learns the training data too closely and performs poorly on unseen data.

The goal is to find a model with appropriate complexity that generalizes well to unseen data.
