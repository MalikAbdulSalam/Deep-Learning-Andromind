How Neural Networks Work
TensorFlow, Keras and PyTorch

Learning Objectives: After this lesson, you will understand how a neural network receives input, performs calculations, makes predictions, calculates error, learns through backpropagation, and updates its parameters. You will also understand TensorFlow, Keras, and PyTorch and how they are related.

1. What is a Neural Network?

A Neural Network is a machine learning model made of interconnected computational units called neurons.

A neural network learns a mapping between inputs and outputs by adjusting parameters such as weights and biases.

Input Data │ ▼ ┌───────────────┐ │ Input Layer │ └───────────────┘ │ ▼ ┌───────────────┐ │ Hidden Layer │ └───────────────┘ │ ▼ ┌───────────────┐ │ Hidden Layer │ └───────────────┘ │ ▼ ┌───────────────┐ │ Output Layer │ └───────────────┘ │ ▼ Prediction

2. Basic Neuron

A neuron receives inputs, multiplies them by weights, adds a bias, and then applies an activation function.

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

Then:

a = f(z)

where:

Symbol Meaning
x Input
w Weight
b Bias
z Weighted sum
f Activation function
a Neuron output

3. How Does a Neural Network Work?

Training a neural network can be understood as a repeated cycle:

Input Data ↓ Forward Propagation ↓ Prediction ↓ Calculate Loss ↓ Backpropagation ↓ Calculate Gradients ↓ Optimizer ↓ Update Weights & Biases ↓ Repeat

4. Step 1 — Input Data

The neural network first receives input data.

Example: Suppose we want to predict whether a student will pass based on:
  • Hours studied
  • Attendance
  • Previous marks
These values become the input features of the network.

For example:

X = [5, 85, 72]

5. Step 2 — Weights

Each input is multiplied by a weight.

z = x₁w₁ + x₂w₂ + x₃w₃ + b

Weights determine how strongly each input influences the neuron.

If the network learns that attendance is very important, it may assign a larger weight to the attendance feature.

6. Step 3 — Bias

Bias is an additional learnable parameter.

z = Σ(wᵢxᵢ) + b

Bias allows the neuron to shift its activation or decision boundary.

7. Step 4 — Activation Function

The weighted sum is passed through an activation function.

a = f(z)

Common activation functions include:

Activation Common Use
ReLU Hidden layers
Sigmoid Binary classification output
Softmax Multi-class classification output
Tanh Some hidden/recurrent architectures

8. Step 5 — Forward Propagation

The complete process of sending information from the input layer toward the output layer is called forward propagation or forward pass.

Input ↓ Layer 1 ↓ Activation ↓ Layer 2 ↓ Activation ↓ Output Layer ↓ Prediction

For a layer:

Z = XW + b

Then:

A = f(Z)

9. Numerical Example

Suppose:

x₁ = 2
x₂ = 3

Weights:

w₁ = 0.5
w₂ = 0.4

Bias:

b = 0.2

Calculate:

z = (2 × 0.5) + (3 × 0.4) + 0.2
z = 1 + 1.2 + 0.2 = 2.4

Using ReLU:

ReLU(2.4) = 2.4

Therefore, the neuron output is:

a = 2.4

10. Step 6 — Prediction

After passing through all network layers, the network produces an output. This is its current prediction.

For a binary classification problem: Output = 0.87 This could be interpreted as approximately 87% model probability for the positive class, depending on the model and output configuration.

11. Step 7 — Loss Function

The prediction must be compared with the actual target. The difference is measured using a loss function.

Loss = Difference between Prediction and Target

Examples:

Task Common Loss
Regression Mean Squared Error (MSE)
Binary Classification Binary Cross-Entropy
Multi-Class Classification Cross-Entropy

12. Step 8 — Backpropagation

Backpropagation calculates how much each learnable parameter contributed to the loss by applying the chain rule of calculus.

Loss ↓ Gradient of Output Layer ↓ Gradient of Hidden Layer ↓ Gradient of Earlier Layers ↓ Gradients of Weights and Biases

The result is a set of gradients such as:

∂L / ∂w

which means the rate at which the loss changes with respect to a weight.

13. Step 9 — Gradient Descent

Once gradients have been calculated, an optimization algorithm updates the model parameters.

w_new = w_old − η × ∂L/∂w

where η is the learning rate.

Important: Backpropagation calculates gradients. The optimizer uses those gradients to update the parameters.

14. Complete Learning Cycle

Training Data │ ▼ ┌─────────────┐ │ Neural Net │ └─────────────┘ │ ▼ Prediction │ ▼ Loss Function │ ▼ Backpropagation │ ▼ Gradients │ ▼ Optimizer │ ▼ Updated Parameters │ └──────────► Repeat

15. What Happens During Training?

Epoch 1:
The network starts with randomly initialized or otherwise initialized parameters and usually produces relatively poor predictions.
Epoch 2:
The optimizer has updated the parameters using gradients, so the model may produce improved predictions.
Epoch 10:
The network has repeatedly adjusted its parameters based on the training data.
Final:
The trained parameters represent patterns learned from the training data.

16. Simple Real-World Example

Suppose we build a neural network to classify images of cats and dogs.

Cat/Dog Image ↓ Pixel Values ↓ CNN Layers ↓ Feature Extraction ↓ Classification Layer ↓ Probability ↓ Cat or Dog

During training:

  1. Image enters the network.
  2. The network extracts features.
  3. The network produces a prediction.
  4. The prediction is compared with the true label.
  5. Loss is calculated.
  6. Backpropagation calculates gradients.
  7. The optimizer updates weights.
  8. The process repeats.

17. What is TensorFlow?

TensorFlow is an open-source machine learning framework developed by Google and widely used for building, training, evaluating, and deploying machine learning and deep learning models.

The fundamental data structure in TensorFlow is the Tensor.

Data │ ▼ Tensor │ ▼ TensorFlow Operations │ ▼ Neural Network │ ▼ Training │ ▼ Saved Model │ ▼ Deployment

Tensor

Dimension Example

1D Vector

18. What is Keras?

Keras is a high-level deep learning API designed to make building and training neural networks easier.

Modern Keras can work with different computational backends, including TensorFlow, JAX, and PyTorch.

Important: Keras and TensorFlow are not simply two names for the same thing. Keras is a high-level API, while TensorFlow is a broader machine learning framework/backend ecosystem. Keras can also be used with other supported backends.

19. Keras Example

import keras
from keras import layers

model = keras.Sequential([
    layers.Dense(64, activation="relu"),
    layers.Dense(32, activation="relu"),
    layers.Dense(1, activation="sigmoid")
])

model.compile(
    optimizer="adam",
    loss="binary_crossentropy",
    metrics=["accuracy"]
)

model.fit(X_train, y_train, epochs=10, batch_size=32)

Keras provides high-level components such as:

  • Layers
  • Models
  • Optimizers
  • Loss functions
  • Metrics
  • Callbacks

20. What is PyTorch?

PyTorch is an open-source machine learning framework developed by Meta and widely used for deep learning research and production.

It provides tensors, automatic differentiation, neural network modules, optimizers, GPU acceleration, and other tools for developing machine learning systems.

Input Tensor ↓ PyTorch Model ↓ Prediction ↓ Loss ↓ Autograd ↓ Gradients ↓ Optimizer ↓ Updated Parameters

21. PyTorch Example

import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 64),
    nn.ReLU(),
    nn.Linear(64, 32),
    nn.ReLU(),
    nn.Linear(32, 1),
    nn.Sigmoid()
)

criterion = nn.BCELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(10):

    optimizer.zero_grad()

    output = model(X_train)

    loss = criterion(output, y_train)

    loss.backward()

    optimizer.step()

    print("Loss:", loss.item())

22. Understanding the PyTorch Training Loop

The four most important lines are: 

optimizer.zero_grad()
output = model(X_train)
loss.backward()
optimizer.step()
Command Purpose
zero_grad() Clears previously stored gradients.
model(...) Performs the forward pass.
loss.backward() Calculates gradients using automatic differentiation.
optimizer.step() Updates model parameters.

24. TensorFlow + Keras Relationship

Keras High-Level Deep Learning API │ ┌──────────┼──────────┐ ▼ ▼ ▼ TensorFlow JAX PyTorch Backend Backend Backend │ ▼ Tensor Operations │ ▼ Hardware Acceleration │ CPU / GPU / TPU

The key idea is that Keras is an API, while TensorFlow, JAX, and PyTorch can serve as supported backends for Keras.

25. TensorFlow vs Keras vs PyTorch

Think of them this way:

TensorFlow: A broad machine learning framework and ecosystem.

Keras: A high-level API for conveniently building and training neural networks, capable of using supported backends.

PyTorch: A complete deep learning framework with tensors, automatic differentiation, neural network modules, optimizers, and deployment tools.

26. Simple Analogy

Imagine building a house.

TensorFlow / PyTorch: The underlying tools, materials, and machinery used to build the system.

Keras: A higher-level interface that makes many common construction tasks easier.

Neural Network: The actual structure you build.

28. Why Do We Need These Frameworks?

Without frameworks, we would need to manually implement many operations:

  • Tensor calculations
  • Matrix multiplication
  • Activation functions
  • Gradient calculations
  • Backpropagation
  • GPU acceleration
  • Optimization algorithms
  • Model saving and loading

Deep learning frameworks automate much of this work.

29. Neural Network Development Workflow

Collect Data ↓ Prepare Dataset ↓ Train / Validation / Test Split ↓ Choose Architecture ↓ Build Model ↓ Choose Loss Function ↓ Choose Optimizer ↓ Train ↓ Validate ↓ Tune Hyperparameters ↓ Test ↓ Save Model ↓ Deploy

30. Important Terms

Term Meaning
Parameter Learnable value such as a weight or bias.
Hyperparameter Value chosen by the developer, such as learning rate or batch size.
Epoch One complete pass through the training dataset.
Batch A subset of training samples processed together.
Iteration One optimizer update, commonly after processing one batch.
Loss A numerical measure used to quantify prediction error.
Gradient Derivative information indicating how the loss changes with parameters.
Optimizer Algorithm that updates model parameters using gradients.

31. The Complete Picture

32. Key Points to Remember

  • A neural network learns by adjusting its parameters.
  • A neuron calculates a weighted sum plus bias and applies an activation function.
  • Forward propagation produces predictions.
  • Loss measures how far predictions are from the target.
  • Backpropagation calculates gradients.
  • Gradient-based optimizers update weights and biases.
  • TensorFlow is a broad machine learning framework and ecosystem.
  • Keras is a high-level deep learning API that supports multiple backends.
  • PyTorch is a deep learning framework with tensors, autograd, neural network modules, optimizers, and more.
  • Both TensorFlow/Keras and PyTorch can train models on CPUs and supported accelerators.

33. Final Summary

How does a neural network learn?

Input → Forward Pass → Prediction → Loss → Backpropagation → Gradients → Optimizer → Updated Parameters → Repeat

TensorFlow: Broad ML framework and ecosystem.

Keras: High-level deep learning API that can use supported backends.

PyTorch: Deep learning framework providing tensors, automatic differentiation, neural network building blocks, optimization, and deployment capabilities.
